# 4. ★★ 새로 나온 것 둘 — **모든 인터페이스에 포트가 열린다 (0.0.0.0:8765)**

창을 띄우니 **Windows 방화벽이 「공용 및 프라이빗 네트워크에서 액세스하도록
허용하시겠습니까?」를 물었다. 허용하지 않았다.** (보안 설정은 내가 바꿀 자리가 아니다)

```
LocalAddress  LocalPort  State
0.0.0.0            8765  Listen
```

**127.0.0.1 이 아니라 0.0.0.0 이다** — 이 기계뿐 아니라 **같은 공유기에 붙은 다른 기기**에서도
닿는다. 열려 있는 것은 **「VC 원격 접속 — 폰의 VC 앱으로 이 QR을 찍어줘」** 페이지고,
경로는 `/eb/v1/ask` 와 `/eb/v1/remote/close` 다.

**막이는 있다** ✓

```
GET  /eb/v1/ask?q=…   → 401 권한 없음
POST /eb/v1/ask        → 401 권한 없음
VC.exe --no-server 로 켜면  → 듣는 포트 없음 ✓
```

★ **그래서 「뚫렸다」가 아니다.** 401 로 막고, 끄는 스위치도 있다. 다만 셋을 짚는다:

1. **바인딩이 0.0.0.0 이다.** 폰이 같은 망에서 붙어야 하니 그럴 만하지만,
   **원격을 안 쓰는 동안에도 늘 열려 있다.** 붙기 전에는 127.0.0.1 로 두고
   **QR 을 띄울 때만 0.0.0.0 으로 올리는** 쪽이 안전하지 않나.
2. **기본이 켜짐이다.** `--no-server` 를 **알아야만** 끌 수 있다.
   오너가 카페·회사 망에서 그냥 켜면 **모르는 새 열린다.**
3. **문 앞에서 방화벽이 묻는다.** 이건 「예/아니오」가 아니라
   **「이 프로그램이 왜 네트워크를 쓰는지」를 오너가 먼저 알아야 하는 자리**다.
   창 어딘가에 **지금 열려 있다는 표시**가 있으면 좋겠다.

★ **그리고 이건 내 지난 완료보고서를 고쳐야 하는 것이다.**
나는 v0.1.76 보고서에 **B6 오프라인 「로컬 전용 · 외부 호출 없음」 Pass**,
**C3 외부 연동 「N/A — 붙는 외부 서비스가 없다」** 로 적었다.
**나가는 호출은 없지만 들어오는 문이 있었다.** 「로컬 전용」은 틀린 말이었다.
→ **고쳐서 다시 낸다.** 내가 안 열어 본 문이었다.
※ 새로 생긴 것인지 전부터 있었는지는 **못 갈랐다** — 판마다 푸는 폴더가 달라
  방화벽이 이번에 처음 물었을 수도 있다.
