## 5. 미해결 결함

| ID | 제목 | 심각도 | 우선순위 | 주입 활동 | 발견 활동 | 원인 | 상태 |
|---|---|---|---|---|---|---|---|
| **D-01** | **같은 폴더를 다시 흡수하면 이미 들어온 글이 사본으로 또 들어온다** | **Critical** | **High** | 설계 | 시스템 | **Missing** (겹침 검사가 이미 들어온 글을 안 본다) | 열림 |
| **D-02** | 본문이 비어 서로 같아지는 파일이 여럿이면 하나가 셈에서 사라진다 | Major | Medium | 코딩 | 시스템 | **Wrong** (셈이 틀림) | 열림 |

### D-01 재현 절차

```
1. 글 2장이 든 폴더를 만든다 (각 40자 이상)
2. VC.exe --흡수 "<그 폴더>" --쓴다      → 2장 들어온다 · 항목 2
3. VC.exe --흡수 "<같은 폴더>"           → 겹친 것 0 · 들인 것 2   ← 여기서 이미 틀렸다
4. VC.exe --흡수 "<같은 폴더>" --쓴다     → 「제목 (제목).md」 2장이 더 생긴다 · 항목 4
```

- 색인은 앞선 2장을 **알고 있다**(`--doctor` 항목 수 2). 자료가 없어서가 아니라 **안 본다.**
- **이 결함은 이미 크게 터진 적이 있다** — 만든 쪽 기록 3183장 중 **388뭉치 12.2%** 가
  「같은 글이 두 나무에서 흡수됐다」로 사본이 됐다. `--사본치우기` 는 그 **증상**을 치우는
  기능이고, **원인은 아직 살아 있다.**
- 곁가지: 사본 이름이 `제목 (제목).md` 로 **제목을 두 번 적는다.**

### D-02 재현 절차

```
1. 한 폴더에 본문이 비는 파일 3개를 둔다 (0바이트 / 앞머리만 / 이진 쓰레기)
2. VC.exe --흡수 "<그 폴더>"
   → 싼 문지기 — 본 것 2 · 들인 것 0 · 겹친 것 0 · 버린 것: 빈 파일 2
   → 파일은 3개인데 본 것이 2다.  2 + 0 + 0 = 2 ≠ 3
3. 셋을 하나씩 따로 넣으면 각각 본 것 1 로 제대로 세어진다  ← 합쳤을 때만 사라진다
```

- 사라지는 글이 **버릴 글뿐**이라 자료 손실은 없다. 다만 「본 것 = 들인 것 + 겹친 것 + 버린 것」
  이라는 **이 도구의 셈 약속이 깨진다.** 「내 파일을 다 봤나」에 틀린 답을 준다.

## ⚠ 정정 (2026-09-06 추가 · v0.1.77 시험 중 발견)

**이 보고서의 B6·C3 판정은 틀렸다. 「로컬 전용」이 아니다.**

v0.1.77 을 띄우자 **Windows 방화벽이 네트워크 접근 허용을 물었다.** 허용하지 않고 확인하니:

```
LocalAddress  LocalPort  State
0.0.0.0            8765  Listen        ← 127.0.0.1 이 아니라 모든 인터페이스
```

여는 것은 **「VC 원격 접속 — 폰의 VC 앱으로 이 QR을 찍어줘」** 페이지이고,
경로는 `/eb/v1/ask` · `/eb/v1/remote/close` 다.

**막이는 있다** — `/eb/v1/ask` 는 GET·POST 둘 다 **401 권한 없음**으로 막히고,
`VC.exe --no-server` 로 켜면 **듣는 포트가 없다.**

### 무엇을 틀렸나

| 원래 적은 것 | 실제 |
|---|---|
| B6 「로컬 전용 · 외부 호출 없음」 Pass | **나가는 호출은 없지만 들어오는 문이 있다.** 「로컬 전용」이 틀렸다 |
| C3 「붙는 외부 서비스가 없다」 N/A | **폰과 붙는 원격 기능이 있다.** N/A 로 넘길 자리가 아니었다 |

### 왜 놓쳤나

**v0.1.76 을 시험할 때 방화벽이 안 물었다.** 판마다 다른 폴더에 푸는데 방화벽 규칙은
경로마다 따로라, 이번 경로에서 처음 물은 것일 수 있다.
→ **「아무 일도 안 일어났다」를 「그런 기능이 없다」로 읽었다.** 포트를 직접 세어 보지 않고
**증상이 없는 것을 근거로 판정했다.** 이 보고서 붙임 C 에 적은
「빈 결과를 통과로 읽기 전에 그 도구가 돌기는 했는지 먼저 본다」의 **세 번째 얼굴**이다.
