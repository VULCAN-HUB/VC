# ★★ 새로 나온 것 — **창 최소 폭이 922 → 1050 으로 늘었다**

```
MoveWindow 로 922 를 주면  → 1050 이 된다
             1000 을 주면  → 1050
             1050 을 주면  → 1050
줄일 수 있는 가장 작은 창 : 1050 x 469
```

**이 판에서 위 띠에 글자를 더한 만큼 최소 폭이 넓어진 것**으로 본다. [짐작이다]

## 이게 왜 걸리나 — **내 잣대 하나가 못 쓰게 됐다**

너희 지시서의 불변 항목에 **「목차 922」** 가 있다. **이제 창을 922 로 못 만든다.**
v0.1.68 부터 열세 판을 **922 에서** 재 왔는데 그 자리가 사라졌다.

## 재 봤다 — **접힘 경로는 살아 있다** ✓

```
창 1050 (= 이제 가장 작은 창) 에서 JUMP7 열기
  위 줄       ← → [메모 ▾]  열에 · 고치기 · …  · 닫기      목차 없다 ✓
  「…」 안     새 항목 / 오늘 일지 / **목차 (3)** ▸ / 서식 넣기 / 지우기 / 문제 알리기 ✓
```

**접히는 길이 죽은 게 아니라 잣대의 숫자가 바뀐 것뿐이다.**
→ **앞으로 「목차 922」 대신 「목차 1050 (최소 폭)」 으로 잰다.** 너희 잣대도 갈아라.

## 네 새 검사는 통과한다

```
창 최소 1050 x 469  ·  네 잣대 1366 x 1032 이하  → 맞다 ✓
내 화면 1920 x 1080 에 들어간다 ✓
```

→ **결함으로 안 적는다.** 네가 그 검사를 넣어 둔 덕에 **넓어졌어도 화면 밖으로는 안 나갔다.**
  ※ 다만 **최소 폭은 한 번 넓어지면 잘 안 좁아진다.** 위 띠에 무엇을 더할 때마다
    이 숫자가 오른다. **1366 까지 남은 폭이 316px 이다.** 지금 알아 두는 게 낫다.

적어 둔다 — 나중에 그 자리에 무엇을 더 넣을 때 폭이 이미 빠듯하다는 뜻이다.
