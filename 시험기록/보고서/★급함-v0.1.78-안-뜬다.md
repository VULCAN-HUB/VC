# ★★ 급함 — v0.1.78 은 **그냥 켜면 안 뜬다.** 여기서 멈춘다

sha256 일치 · exe 0.1.78.0. **더 재지 않고 먼저 알린다.**

## 증상

```
VC.exe            (아무 스위치 없이 = 제일 흔한 길)

Traceback (most recent call last):
  File "eb.py", line 1212, in <module>
  File "eb.py", line 179, in main
UnicodeEncodeError: 'cp949' codec can't encode character '⚠' in position 2:
                    illegal multibyte sequence
```

**창이 안 뜬다.** 뜨는 것은 PyInstaller 오류 상자다 —
창 제목 **「Unhandled exception in script」 · 49MB**.
(진짜 VC 창은 494MB다. **메모리로 갈랐다** — 43-4 에서 세운 그대로다)

## 원인

이번 판에 넣은 **켤 때 찍는 경고문의 `⚠` (U+26A0)** 다.
Windows 콘솔 기본 인코딩이 **cp949** 라 그 글자를 못 찍고 **그 자리에서 죽는다.**

지시서 37 「가」에 네가 적은 그 두 줄이다:

```
⚠ 같은 공유기의 다른 기기에서도 이 자리에 닿는다 (토큰 없으면 401로 막힌다).
```

**알리려고 넣은 말이 프로그램을 죽였다.**

## 갈래 — 어디까지 죽나

```
VC.exe                  ★ 죽는다. 창 안 뜬다
VC.exe --no-server      뜬다 ✓  (창 「VC」 · 494MB)   ← 서버를 안 켜니 그 말을 안 찍는다
VC.exe --doctor         돈다 ✓  종료값 0
VC.exe --사본치우기       돈다 ✓  종료값 0
VC.exe --no-ui          죽는다 (같은 자리)
```

→ **죽는 것은 「서버를 켜면서 그 경고를 찍는」 길뿐이다.** 나머지는 다 산다.
→ 그래서 **`--no-server` 가 우회로가 된다.** 다만 그건 **원격을 포기하는 것**이고,
  무엇보다 **오너는 그냥 켠다.**

## ★ 이건 v0.1.64 의 재현이다

그때도 **「제일 흔한 길(그냥 켜기)을 아무도 안 밟고 있었다」**였다.
너는 그때 **「검사에 박았다」**고 했는데 **또 뚫렸다.**

이번엔 자리가 하나 더 있다 — **그때 검사는 「죽지 않는다」만 봤을 것이다.**
이 크래시는 **콘솔이 cp949 일 때만** 난다. 네 자리에서 UTF-8 로 띄웠으면 안 보인다.

→ **검사에 「콘솔 인코딩이 cp949 인 채로 그냥 켜기」를 넣어야 한다.**
  한국어 윈도우의 **기본값**이 그것이다. 오너 PC 도 그렇다.

## 고칠 길 (내 생각)

1. **`⚠` 를 쓰지 마라.** 이 프로그램의 다른 말은 전부 `★` 를 쓰는데 그건 잘 찍힌다.
   `★` 로 바꾸면 끝난다. (`★` 는 cp949 에 있다)
2. 아니면 켤 때 **stdout 을 UTF-8 로 다시 감싸라.** 다만 그건 이 자리 하나 때문에
   전체를 건드리는 것이라 1번이 싸다.
3. **어느 쪽이든 「글자 하나가 못 찍혀도 프로그램은 살아야 한다」** — 알리는 말이
   프로그램을 죽이면 안 된다.

## 내가 이번 판에서 잰 것 · 안 잰 것

**잰 것**

```
□ --doctor 에 「듣는 자리」가 있나        ✓ 있다
   「듣는 자리 : 0.0.0.0:8765 ← 같은 공유기의 다른 기기에서도 닿는다 (--no-server 로 끈다)」
   → 이건 잘 됐다. 창을 못 띄워도 여기서 알 수 있다는 네 말대로다
□ 켤 때 「⚠ 같은 공유기의…」 두 줄이 뜨나  ✗ **못 뜬다. 그 줄이 프로그램을 죽인다**
```

**안 잰 것** — **여기서 멈췄다.** 그냥 켜지지 않는 판으로 나머지를 재면
「무엇이 이 판 탓이고 무엇이 원래 그런지」를 못 가른다.

```
나. 빈 글 회귀 (이번 판 본론)   안 쟀다
다. 목차 1500 · [[링크]]        v0.1.77 에서 이미 다 쟀다 (아래)
라. 이건 안 바뀌어야 한다        안 쟀다
```

※ **다만 「다」는 이미 답이 있다** — 오너가 다시 재라 해서 **v0.1.77 에서 채웠다.**

```
목차 1500   위 줄에 「목차 (3)」 ✓ 안 겹친다 ✓
[[링크]]    커서가 손모양인 자리를 눌러 「안 먹는 말투」로 넘어감 ✓
```

★ 그리고 그 자리에서 하나 나왔다 — **창 1500 에서는 찾은 결과 줄을 눌러도 카드가
안 열린다.** 세 번 다 안 열렸고, **922 로 줄여 열고 1500 으로 넓히면** 열린다.
**결함이라 안 적는다** — 내 겨냥 탓일 수 있고, 아직 커서 모양으로 안 물어봤다.
