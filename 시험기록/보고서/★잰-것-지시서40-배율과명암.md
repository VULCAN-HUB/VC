# 지시서 40 — 배율 · 글자/명암. **판은 v0.1.80 그대로.**

**둘 다 통과.** 다만 **어떻게 쟀는지를 먼저 밝힌다** — 방법이 다르면 값의 뜻이 다르다.

---

# ★ 먼저 : 나는 화면 배율을 **안 바꿨다**

지시서는 「설정 > 디스플레이 > 배율을 바꾸고 **로그아웃·재로그인** 뒤 켜라」였다.
**그건 이 PC 의 시스템 설정을 바꾸고 오너를 로그아웃시키는 일이라 내가 할 자리가 아니다.**

대신 **Qt 가 제 layout 을 그 배율로 그리게 하는 길**로 쟀다:

```
QT_SCALE_FACTOR=1.25  VC.exe
QT_SCALE_FACTOR=1.5   VC.exe
```

**환경 변수 하나뿐이고 시스템은 손대지 않는다.** 그리고 실제로 먹었다 —
최소 창이 1050 → 1304(×1.25) → 1562(×1.5) 로 **정확히 배율만큼** 커졌다.

## 이 값이 무엇을 말하고 무엇을 말하지 않나

```
말한다     Qt 가 배율에 맞춰 layout 을 다시 잴 때 최소 창이 얼마나 커지나
           그 크기에서 글자가 잘리나 · 겹치나 · 「…」 안의 것이 살아 있나
말 안 한다  윈도우가 DPI 를 어떻게 알려 주는지 · 글꼴 렌더링이 어떻게 달라지는지
           DPI 를 모르는 앱을 윈도우가 늘려 그릴 때 흐려지는 것
```

→ **「창이 들어가나 · 글자가 잘리나」는 이걸로 답이 된다.** 그게 지시서가 물은 것이다.
  **「진짜 배율에서 눈에 어떻게 보이나」는 아직 안 잰 것으로 남긴다.** [그렇게 판단했다]

# 가. 배율 — **125% · 150% 둘 다 들어간다**

```
                 가장 작은 창        쓸 화면(작업표시줄 뺀)      들어가나
100%             1050 x 469         1920 x 1032              ✓
125%             1304 x 576         1920 x 1032              ✓
150%             1562 x 684         1920 x 1032              ✓  폭 여유 358px · 높이 여유 348px
```

★ **네가 걱정한 자리 — 「1920x1080 에 150% 면 쓸 폭이 1280 이다」**
그 셈으로도 맞는다. **최소 폭은 논리 화소로 1050 그대로**이고 1280 안에 든다.
**여유가 230px 이다.** 물리 화소로 보면 1562 가 1920 안에 든다 — 같은 말이다.

## 150% 에서 눈으로 본 것

```
□ 위 띠 「★ 원격 열림 :8765」   안 잘린다 ✓  (별표 · 글자 · 포트 다 보인다)
□ 아이콘·단추가 겹치나          안 겹친다 ✓
□ 카드가 열리나                열린다 ✓ · 위 줄에 목차 없다 (접힘 그대로)
□ 「…」 안에 목차가 있나        **목차 (3) ▸** 있다 ✓ · 차림표도 안 잘린다
```

**125% 도 같다.** 최소 창이 1304 로 커진 것 말고 달라진 것이 없다.

# 나. 글자 크기 · 명암 — **값으로 쟀다**

「읽기 힘들다」는 사람마다 다르니 **화면을 찍어 화소를 직접 재서 명암비를 냈다.**
(WCAG 기준 : 본문 4.5:1 · 큰 글자 3:1)

```
자리                    글자색            바탕색        명암비    판정
─────────────────────────────────────────────────────────────────────
★ 위 띠 「원격 열림」     (206,146, 69)   (10,10,11)    7.37    AA 통과
  위 띠 「VULCAN」        (242,230,224)   (10,10,11)   16.18    AA 통과
  아래 띠 왼쪽 말          (242,230,224)   (22,13,11)   15.66    AA 통과
  아래 띠 오른쪽 경고       (225,190,132)   (10,10,11)   11.21    AA 통과
  그물 이름표             (174,164,158)   (19,11,10)    7.97    AA 통과
─────────────────────────────────────────────────────────────────────
  검색창 안내 글자         ( 99, 94, 91)   (10,10,11)    3.09    큰 글자만 AA
✗ 오른쪽 붉은 머리글       (157, 41, 23)   (10,10,11)    2.60    ★ 낮다
✗ 오른쪽 잿빛 설명         ( 79, 74, 73)   (10,10,11)    2.27    ★ 낮다
```

## ★★ 제일 중요한 자리는 통과했다

**「★ 원격 열림 :8765」가 7.37 이다.** 이번 판의 경고가 **잘 읽힌다.**
아래 띠 경고도 11.21 로 높다. **말해야 할 것은 잘 보인다.**

## 낮은 둘 — **결함으로 안 적는다. 다만 값을 적어 둔다**

`// 찾은 것` 같은 **붉은 머리글(2.60)** 과 그 밑 **잿빛 설명(2.27)** 이 낮다.

**결함으로 안 적는 까닭 :**
- 이 둘은 **꾸밈 글자**다. 머리글은 「무엇이 아래 있는지」 알려 주는 이름표이고
  설명은 한 번 읽으면 그만인 안내다. **일을 못 하게 막는 자리가 아니다.**
- 어두운 SF 꼴 화면에서 **일부러 낮춘 것**으로 보인다. 다 올리면 그 꼴이 깨진다.
- **오너가 며칠 써 왔고 안 불편하다고 한 적이 없다.**

**그래도 값을 적어 두는 까닭 :**
- **밝은 데서 노트북을 쓰면 2.27 은 안 보인다.** 「나는 안 불편하다」와
  「밝은 창가에서도 보인다」는 다른 말이다.
- 나중에 누가 「글자가 안 보인다」고 하면 **어느 자리인지 이 표로 바로 찾는다.**
- **내 눈으로 「읽을 만하다」고 적었으면 그 말은 못 쓴다.** 나는 화면을 찍어서 볼 뿐이라
  **눈으로 읽기 편한지는 원래 내가 못 재는 것**이다(「여기서는 못 잰다」 가 갈래).
  **명암비는 내가 잴 수 있는 값이라 그것만 냈다.**

→ **오너가 정할 자리다.** 올릴 것인지, 지금 꼴을 지킬 것인지.
