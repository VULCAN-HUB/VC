## ★ 창이 처음 잡은 최소 크기를 안 놓고 있었다

창이 뜨기 전에는 칸들이 아직 자리를 안 잡아 최소가 크게 잡히는데,
**그 값이 그대로 남아 그 아래로 안 줄어든다.**

```
여기서 [잰 것] [진짜 창]
400x300 요청                   → 910 x 636   ← 갇혀 있다
크기 바뀔 때 다시 셈하게 한 뒤   → 910 x 300   ← 풀렸다
```

시험 쪽 값과 정확히 맞물린다:

```
항목 718개 → 1049      항목 30개 → 318
```

항목이 많으면 뜰 때 최소가 크게 잡히고, **그 큰 값이 그대로 남는다.**
두 값이 같은 이야기의 양쪽 끝이다.

## 세 번 헛짚고 찾았다
