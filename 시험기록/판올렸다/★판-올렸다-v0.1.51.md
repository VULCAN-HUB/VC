## ★ 색인이 없어지면 시작 항목이 하나 더 생기던 것

파일엔 이미 있는데 **색인만 보고** 만들었다. 그래서 8월 폴더에 `VC.md` 가 있는데도
9월 폴더에 또 만들었고, 같은 제목 둘이 되어 ⚠ 가 떴다.

**색인은 언제든 다시 만들 수 있고 파일이 원본이다.** 그러니 「있나 없나」는
원본에 물어야 한다. 이제 파일을 본다.

```
[잰 것] 고침 되돌린 판   VC.md 2개
[잰 것] 고친 판          VC.md 1개
```

★ 사람에게도 나는 자리다 — **색인이 깨지거나, 자리를 옮기거나, 기록만 백업했다
되살릴 때.** 그때마다 「VC」가 하나씩 는다.

## ⚠ 뒤가 잘리던 것

원래 「⚠ 같은 제목 2개(VC…)」로 적힌다. 그런데 아래 띠는 **뒤엣것부터 잘리는데
경고가 맨 뒤에** 있었다. 그래서 `⚠` 만 남았다.

**경고를 맨 앞으로 옮겼다:**

```
⚠ 같은 제목 2개(VC…)  /  적은 것 0/2  /  보임 400/719  /  연결 74
```

앞 판에서 「값진 것을 앞에 둔다」를 아래 띠 가운데엔 쓰고 **경고엔 안 썼다.**
