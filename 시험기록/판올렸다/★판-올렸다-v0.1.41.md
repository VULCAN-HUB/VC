## 이번에 고친 것 넷

**1) ★ `--색인다시` 가 통째로 다시 쌓는다.**
안에서 부르던 것이 「**바뀐 파일만** 다시 읽는」 길이었다. 파일은 그대로인데
읽는 **규칙**이 바뀐 때는 아무것도 안 바뀌어서 **0.3초에 끝나고 옛 값이 남았다.**
이제 파일에서 나온 것을 통째로 비우고 다시 쌓는다.

**규칙이 바뀌면 `--색인다시` 한 번이면 된다.** 흡수를 다시 돌릴 필요 없다.

**2) 자전 셈에 「초당 판수」와 「지금 간격」이 붙는다.**
「기대보다 얼마나 늦었나」만 말하면 못 읽는다 — **늦춤이 걸려 있으면 밀림 몫은
저절로 내려간다.** 느려진 것이 좋아진 것처럼 보인다.

**3) 세션 기록 안의 규칙도 구한다.**
줄 앞에 사람이 붙인 딱지(`규칙:` `결정:` `교훈:` `원칙:` `주의:` `금지:` `약속:` `정책:`)가
있으면 문지기가 버린다 해도 남긴다. **볼트 1260 조각에서 49개(3.9%)**만 걸리고
규칙 문서와 겹치는 것이 하나도 없었다.

**4) 붙는 출처에서 날짜와 꼬리말을 뗀다.**

```
기술스택 (2026-07-01-ourmemories-session)  →  기술스택 (ourmemories)
```
