## 고친 다섯

**1) 잃은수 경보가 거짓이었다.** 「쓴 것」을 기록 **전체** 항목 수와 견줬다 —
빈 자리에 처음 쓸 때만 맞는 셈이었다. 이제 **「는 것」과 「쓴 것」**을 견준다.

```
**188개 썼다.**
  기록에 든 항목: 529 → 717개 (는 것 188)
```

**2) 「못 알아들은 것」을 0일 때도 찍는다.** 네 근거 그대로 — 안 찍으면
「쟀는데 0」과 「아예 안 쟀다」가 안 갈리고, 그러면 **20% 잣대 자체가 없는 것**이다.
죽었을 때만 별표를 두른다.

**3) 앞에 붙은 번호를 뗀다.** 「1)」 「1-1)」 「(가)」 「★」.
떼고 남는 것이 너무 짧으면 안 뗀다.

**4) 괄호가 열린 채 끝나면 그 앞에서 끊는다.** 네가 준 진짜 제목으로 재 봤다:

```
후속 4건 (2026-07-11(2), 커밋 245bfbf·6d034dc     →  후속 4건…
Second Brain — Vault 규칙 (Claude 저장·참조 계약   →  Second Brain — Vault 규칙…
확인된 사실 (재사용)                              →  그대로 (닫혀 있으니 안 건드림)
```

**5) 짧은 제목에 출처를 붙인다.** 글자 다섯 자 미만이면 겹치든 안 겹치든.
「참고」 → 「참고 (workspace-storage-rule)」.
네가 짚은 대로 **「기술스택」 「큰 그림」이 정확히 4자**라 문턱에 걸린다 —
다섯이 맞는 자리인지는 나도 모른다. **이번에 볼트를 다시 돌려 보고 눈으로 판정해 달라.**

## 새로 생긴 것 둘

**막힌 것 열두 개 미리보기** — `vc-흡수.txt` 끝에 출처·줄과 함께 찍힌다.
여기서 먼저 돌려 봤더니 **막힌 것 중에 남겼어야 할 게 눈에 띄었다.**
80%를 거른 볼트 자리에서 네가 그 열둘을 봐 달라. **이번 판의 본론이다.**

**빼고 재는 길** — 파일을 안 옮기고 목록에서만 뺀다.

```powershell
.\VC.exe --찾기점수 --빼고 "점검보고서"
```

## 이번에 두 쪽이 다 조심스럽게 적어서 이긴 자리

네가 「내 화면 탓일 수도 있다」를 남겨 뒀고, 내가 「재현 못 했다」에 **가르는 법**을
붙였다. 그래서 **없는 결함이 5초에 취소됐다.**

「없다」만 보냈으면 너는 「내 자리에서만 나나」로 더 팠을 것이고,
네가 「깨졌다」로 잘라 적었으면 나는 멀쩡한 자르기를 뜯어고쳤을 것이다.

## 그리고 오늘 다섯 번이 같은 자리였다

네가 「규칙으로 적어 둘 만하다」고 한 그것 — 적어 뒀다.

| 이상해 보인 것 | 의심한 것 | 실제 |
|---|---|---|
| 529개도 2분 넘는다 | 알고리즘 | 프로그램이 **안 하는 짓을 쟀다** |
| 같은 조각이 다르게 판정 | max_tokens | **그 사이 자료를 고쳤다** |
| 세어보기 ≠ 쓰기 | 흡수가 흔들림 | **파일을 더 넣었다** |
| 자리별 속도 차이 | PC 성능 | **자료 차이** |
| 한글 반 토막 | 바이트 자르기 | **콘솔 인코딩** |

**전부 잰 값은 진짜였는데 원인을 프로그램에서 찾았다.**

순서: **①같은 입력으로 두세 판 돌려 한결같은지 먼저 잰다 ②그 사이 무엇이 바뀌었는지
적는다 ③그러고도 남으면 프로그램을 뜯는다.**
