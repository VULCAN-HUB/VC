# 물음 둘 다 답한다 — **기록 자리를 새로 잡아라. 자료는 네가 만들어라**

물음 잘 올렸다. **둘 다 네가 물어야 맞는 자리였다.**
특히 「빈 창고라고 간주할 수 없다」로 멈춘 것 — **그 판단이 옳다.**
항목 1개짜리 창고에서 잡은 기준값은 「빈 창고 기준값」이 아니다.

---

# 1. 그 항목 1개의 정체 — **옛 판이 남긴 것이다**

```
기록 자리에 2026-08-29 진단 묶음이 같이 있다  →  옛 설치본이 쓰던 자리다
항목 「VC」 는 그때 창이 처음 켜지며 만든 씨앗 글이다
판 적합률 0/1 = 그 글이 **옛 형식(0판)** 이라는 뜻이다 — 그래서 0% 가 맞다
```

**지우지 마라.** 잘 뒀다. 그 자리는 그대로 두고 **새 자리를 따로 잡는다.**

# 2. ★ 기록 자리를 새로 잡는 법 — 두 가지, 둘 다 공식이다

## 가. 파일 한 장으로 가리킨다 (아이콘으로 켜도 먹는다 — **이걸 권한다**)

`VC.exe` 가 있는 폴더에 **`기록자리.txt`** 를 만들고 **첫 줄에 자리만** 적는다.

```
C:\VC시험\창고
# 두 번째 줄부터는 아무 말이나 적어도 된다 — 첫 줄만 읽는다
```

- 폴더가 없으면 만들어 준다.
- **못 쓰는 자리(오타·빠진 외장)면 조용히 따르지 않는다** — 기본 자리로 돌아간다.
  그러니 `--doctor` 로 **실제로 그 자리를 쓰는지 반드시 확인해라.**

## 나. 환경 변수 `VC_DATA`

```
cmd :   set VC_DATA=C:\VC시험\창고 && VC.exe --doctor
파워셸:  $env:VC_DATA="C:\VC시험\창고"; .\VC.exe --doctor
```

- **그 창에서 켠 것에만 먹는다.** 아이콘으로 켜면 안 붙는다.
- 한 번 재고 마는 데는 편하지만, **창을 열었다 닫았다 하며 여러 번 잴 거면 가.** 를 써라.

## 다. 자리를 바꾼 뒤 반드시
```
VC.exe --doctor
□ 「기록 자리」가 네가 정한 자리로 바뀌었나   ← 안 바뀌었으면 위 둘 중 하나가 안 먹은 것
□ 항목 수 0 인가                            ← 창을 아직 안 켰으면 0 이 맞다
```

★ **창을 한 번 켜면 씨앗 글 「VC」가 자동으로 하나 생긴다**(이번 판에서는 1판으로 생긴다).
그러니 기준값 표에는 **「빈 창고 = 0장」과 「창 한 번 켠 뒤 = 1장」을 갈라 적어라.**
그 씨앗 글의 판 적합률이 **1/1 (100%)** 인지 봐 줘 — 옛 자리에서 0/1 이 나온 것과
견주는 값이다.

# 3. 흡수할 자료 — **네가 만들어라. 그게 더 낫다**

내가 줄 사본 폴더는 없다(있어도 오너 개인 자료라 못 준다).
**네가 만든 자료가 오히려 낫다** — 무엇이 들어갈지 네가 아니까 셈이 맞는지 바로 안다.

## 이렇게 만들어라 (파워셸)

```powershell
$뿌리 = "C:\VC시험\자료"
New-Item -ItemType Directory -Force $뿌리, "$뿌리\메모", "$뿌리\회의" | Out-Null

# 1) 평범한 글 여러 장 — 소제목이 있는 것과 없는 것을 섞어라
# 2) 아래 다섯 가지를 일부러 섞어 넣어라 ★ 이게 값진 자료다
```

```
① 소제목이 여럿인 긴 글 (## 로 서너 칸)      → 두 단 꺼내기·목차를 재는 자리
② 소제목이 하나도 없는 글                    → 그때도 되나
③ 본문이 아예 빈 파일 · 앞머리(---)만 있는 파일 → 「버린 것」에 제대로 들어가나
④ **내용이 똑같은 파일 두 장** (이름은 다르게)  → --사본치우기 가 잡나
⑤ [[다른 글 제목]] 링크가 든 글 두어 장       → 연결·그물이 생기나
⑥ 한글 이름 파일 · 이름에 괄호나 공백이 든 파일
```

**몇 장을 넣었는지 네가 세어 두고**, `--흡수` 가 말하는 「본 것」과 맞는지 봐라.
안 맞으면 그게 결함이다.

★ 진짜 자료를 쓰고 싶으면 **버려도 되는 사본 폴더**를 골라라 — 원본을 직접 가리키지 마라.
`--흡수` 는 읽기만 하지만, **원본에 대고 시험하지 않는 것**이 규칙이다.

# 4. 그래서 순서

```
1) 기록자리.txt 로 새 자리를 잡는다  →  --doctor 로 자리·항목 0 확인
2) 창을 한 번 켠다                  →  씨앗 글 1장 · 적합률 1/1 인지 확인
3) C:\VC시험\자료 를 만든다 (위 여섯 가지 섞어서. 몇 장인지 세어 둔다)
4) --흡수 (세어만) → --흡수 --쓴다 → --흡수 (한 번 더, 겹침 확인)
5) 지시서 01 의 기준값 표를 채운다
```

---

★ **네가 한 두 가지가 특히 옳다:**
「빈 창고가 아니니 기준을 못 잡는다」로 **멈춘 것**, 그리고
**기존 자료를 안 지운 것.** 지웠으면 그 자리가 옛 판 시험대였는지 아무도 모르게 됐다.
막히면 지금처럼 물어라 — 짐작으로 적힌 값은 나중에 다 다시 재야 한다.
