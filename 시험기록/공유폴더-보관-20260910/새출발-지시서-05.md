# 1. 물음 3 — 「전부 겹침」은 **내 말이 부정확했다**

네 관찰이 맞다.

```
재흡수: 조각 9 = 겹침 4 + 후보 5   → 그 5는 **모델에게 다시 물어보고 다시 버려진다**
최종 신규 0 은 성립한다
```

**겹침으로 잡히는 것은 「저장된 글」뿐**이다. 처음에 버려진 조각은 어디에도 안 남아서
다음번에 **또 물어본다.** 그러니 「전부 겹침」이 아니라 **「저장된 것은 겹침, 버려진 것은
다시 심사」**가 맞는 말이다. 지시서 04 의 그 줄을 이렇게 고친다:

```
틀림:  겹친 것이 전부 · 들인 것 0
맞음:  **최종 신규 0** · 저장된 조각은 겹침으로 잡힘 · 버려진 조각은 다시 심사됨
```

★ 이건 **고칠 값이 있는 자리**로 적어 둔다 — 같은 폴더를 열 번 부으면 버려진 조각을
열 번 물어본다(네 자리에서 35초). 다만 버린 것을 기억해 두면 **문지기를 고쳤을 때도
옛 판정이 굳는다.** 그 맞바꿈이라 오너에게 올린다.

# 2. 「들인 것」이라는 이름을 고쳤다 — 네가 헷갈린 그 자리

```
예전:  본 것 9 · 들인 것 5 · 겹친 것 4      ← 「5개 저장됐다」로 읽힌다
지금:  본 것 9 · 후보 5 · 겹친 것 4        ← 싼 문지기를 지난 수일 뿐
```
**이름이 셈을 거짓말하게 두면 안 된다.** 네 말 그대로다.

# 3. 물음 4 — 「엔진 — 글 모델 안 올라옴」 **이것도 내 말이 틀렸다**

그 줄이 뜨는 갈래는 **모델이 없다**가 아니라 **서버가 답을 안 했다**였다.
둘을 같은 말로 적어 놓아서, 모델을 제대로 넣고도 「안 올라옴」으로 보였다.

```
지금:  서버가 답 없음      → 「엔진 —  서버에 못 물어봤다」
       모델 있고 안 올라옴  → 「엔진 llama · 모델 1개 대기」
       올라옴             → 「엔진 llama · <이름> 올라옴」
```
□ 이 판에서 그냥 켠 창이 어느 말을 하는지 봐 줘. **「못 물어봤다」가 나오면
  창이 서버에 못 닿는 것**이고 그건 따로 잡을 결함이다.

# 4. 물음 2 — 긴 글 시험: **원본을 창고에 그대로 넣어라. 그게 정식 길이다**

```
파일이 원본이다. 기록 자리의 글 폴더에 .md 를 그대로 복사하면 그게 곧 항목이다.
(창이 떠 있으면 몇 초 안에 알아채고, 아니면 다음에 켤 때 잡는다)
```

흡수가 소제목마다 쪼개는 것은 **흡수 자료가 대개 잡다한 덩어리**라서다 —
사람이 쓴 글 한 편을 그렇게 쪼갤 이유는 없다. **네가 하려는 장문 시험은 흡수가 아니라
「사람이 쓴 긴 글」 쪽이 맞다.**

```
□ 3000자·소제목 4개짜리 원본을 글 폴더에 복사
□ 1단 검색 → headings 에 소제목 4개가 오나 · 응답 몇 자인가
□ 2단 heading=<하나> → 그 토막만 오나 · 몇 자인가
□ 원본 전체 글자 수와 견줘라   ← 이 세 값이 이번 시험의 답이다
```

※ 「흡수가 원본 계층을 보존하는 공식 방법」은 **지금 없다.** 그게 필요한지는
오너가 정할 자리라 그대로 올린다.

# 5. 물음 1 — 설명글이 버려진 것: **자료를 보내 줘. 내가 재겠다**

```
공유폴더에 fixtures-realistic 폴더를 통째로 올려 줘 (원문 그대로)
```

문지기의 잣대는 **「일하는 방법이나 도구 쓰는 법을 적어 둔 설명은 남긴다」**이다.
그러니 **백업 절차 설명이 버려진 것은 잣대와 어긋난다** — 네 기대가 맞다.
다만 그 판정이 **글 탓인지 문지기 탓인지**는 원문을 봐야 안다. 내 쪽에서 같은 글을
돌려 보고, 문지기 탓이면 고친다. **짐작으로 안 고친다.**

★ 「6조각 중 3통과(50%) · 불필요 2조각은 2제외(100%)」처럼 **분모를 갈라 적은 것**이
좋다. 그리고 「소규모 자체자료라 일반 성능으로 확대하지 않는다」도 옳다.
