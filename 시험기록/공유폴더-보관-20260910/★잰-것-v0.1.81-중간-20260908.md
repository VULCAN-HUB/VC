## 4. 사람 자리에서 관측한 것

- 새 항목 클릭으로 항목 수 1→2. 한글·공백·괄호 제목 '시험 메모 (한글)' 작성 가능.
- 소제목 3개, [[VC]] 링크, #테스트 태그가 있는 본문 입력. '저장했어' 메시지와 실제 Markdown 파일 생성을 확인.
- 읽기 모드에서 제목 3개가 목차(3)로 표시되고 본문 서식/링크/태그가 표시됨. 목차 선택 이동, 링크를 눌러 이동, 태그 검색은 아직 미검증.
- UIA 편집 필드 set_value는 도구의 CacheRequest 오류가 나서 클릭·키보드 입력으로 대체 성공. 이것은 프로그램 저장 결함으로 세지 않는다.
- 테스트 글에 외부 파일 쓰기로 고유 표식을 추가. 23:21:15 수정 → 23:21:43 화면에서 표식 확인(28초 이내 관측). 사이에 --doctor가 실행됐으므로 GUI 자체 감지만으로 반영됐다고 단정하지 않는다. 자동 감지 지연을 별도로 재측정해야 함.
- 읽기 모드 아래에 링크와 태그가 중복 안내되어 연결된 항목을 알아볼 수 있음.
- 불편: '엔진 — 서버 꺼짐'과 '★ 원격 열림 :8765'가 동시에 나와 어떤 서버가 꺼진 것인지 처음에는 혼동된다. 실제 원격 API는 응답했음. 서로 다른 서버임을 더 분명히 표시하면 좋음.
- 불편: 어두운 배경 위 작은 어두운 글씨의 안내·컨트롤이 눈에 잘 들어오지 않음. 색상 대비 수치 측정은 하지 않았으므로 접근성 기준 위반 판정은 아님.
- 새 항목이 즉시 생성되는 흐름이어서 본문 쓰기 전에 빈 항목이 생기는지 불안할 수 있음. 실제 빈 항목 정리/취소 동작은 미검증.
- 30분 탐색 세션은 아직 미완료. 옵시디언과 동일 시나리오 비교 실행도 하지 않음.

## 5. 원격 표시와 AI 꺼내기 실측

- 일반 실행: 원격 열림 표시 있음. 인증 없는 검색 HTTP 401.
- --no-server 실행: 원격 열림 표시 없음, API 연결 실패 확인.
- 툴팁 3요소는 미검증. 민감한 주소/토큰 값은 이 보고서에 기재하지 않음.

씨앗 글만 있을 때 검색 응답 전체 184자, body 없음.
직접 만든 테스트 글의 본문 110자에서 다음을 측정(응답 문자 수는 PowerShell 문자열 Length 기준, wire bytes 아님):

| 요청 | HTTP | 전체 응답 문자 수 | 확인 내용 |
|---|---:|---:|---|
| 검색 목록 | 200 | 211 | body 없음, 소제목 3개·summary·chars·links 존재 |
| heading=실행 | 200 | 97 | text 32자, 실행 표식만 있고 준비/마무리 표식 없음 |
| 없는 소제목 | 404 | 104 | 실제 소제목 3개 목록, 전체 본문 없음 |
| heading 없이 글 읽기 | 200 | 200 | 전체 text 110자, 3구간 포함 |
| 검색 full=1 | 200 | 341 | body 포함 |

모두 작은 자체 테스트 글 기준이다. 긴 글/다량 자료에서의 응답 크기는 아직 측정하지 못했다.
