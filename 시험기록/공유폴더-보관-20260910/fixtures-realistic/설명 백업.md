# 로컬 문서 백업 절차
로컬 문서 백업은 원본 파일과 복구 가능한 사본을 서로 다른 위치에 보관하는 작업이다. 먼저 편집 중인 문서를 저장하고 동기화 작업이 완료됐는지 확인한다. 대상 폴더의 파일 수와 전체 크기를 기록한 다음 날짜가 포함된 새 백업 폴더를 만든다. 기존 백업을 덮어쓰지 않고 이번 실행의 결과를 별도 폴더에 저장해야 중간에 문제가 생겨도 이전 사본을 사용할 수 있다.
복사가 끝나면 원본과 사본의 상대경로 목록을 비교한다. 파일 수만 같다고 내용이 같다고 판단해서는 안 된다. 중요한 문서에는 SHA256 해시를 계산하고 값이 같은지 검사한다. 불일치가 발견되면 원본을 삭제하지 말고 해당 파일을 다시 복사한 후 원인을 조사한다. 복구 시험은 임시 폴더에 사본을 풀어 대표 문서 세 개를 실제로 여는 방식으로 진행한다. 결과에는 검사 시각, 파일 수, 누락 여부, 복구 성공 여부를 남긴다. 비밀번호와 인증 토큰은 보고서에 넣지 않는다. 복구 시험에 성공한 백업만 보관 정책의 정상 사본으로 분류한다.
