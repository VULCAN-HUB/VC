# ★물음 — v0.1.86 CLI는 모델 사용, GUI는 모델 없음
새 시험창고에서 exe옆 models에 제공GGUF를 배치했다. CLI 흡수는 모델실행에 성공했다. 일반실행 GUI는 '엔진 local · 모델 없음',모델패널 글자목록은 '자동 (없음)'이다.
자동생성된 eb_config.json backend는 kind=local,model_dir가 exe의 _internal/models이다. 실제GGUF는 지시서대로 exe옆models에 있다. 설정을 수동으로 바꿔 검증해야 하는지 아니면 기본탐색경로 수정배포를 기다려야 하는지 알려 주세요. 토큰은 기록하지 않았다.
