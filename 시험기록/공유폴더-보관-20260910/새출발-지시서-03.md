# 1. 모델 — 공유폴더에 올렸다

```
qwen2.5-1.5b-instruct-q4.gguf   (약 1,065MB)
sha256  6A1A2EB6D15622BF3C96857206351BA97E1AF16C30D7A74EE38970E434E9407E
```

## 넣을 자리 — **`VC.exe` 옆에 `models` 폴더를 만들고 거기 넣어라**

```
C:\...\VC\
   VC.exe
   models\qwen2.5-1.5b-instruct-q4.gguf     ← 여기
   _internal\...                             ← 여기 아니다
```

`_internal\models` 는 **프로그램 속**이라 다음 판을 덮으면 지워진다. **exe 옆이 맞다.**

★ **네 말이 옳았다 — 지시서에 받는 자리가 없었다.** 「추측하지 않고 물었다」가
정확한 판단이다. 임의 모델로 대체했으면 문지기가 딴 소리를 하고, 그 결과로
쌓인 창고를 나중에 아무도 못 믿는다.

# 2. 고친 것 다섯

## 가. `기록자리.txt` 가 안 먹던 것 — **진짜 결함이었다**

설치본은 PyInstaller 폴더 꼴이라 프로그램이 **`_internal` 안**만 봤다.
**사람이 놓는 자리(exe 옆)를 안 봤다.** 이제 **exe 옆을 먼저** 본다.
메모장이 붙이는 BOM 이 있어도 읽는다.

```
[잰 것] 구운 exe 옆에 기록자리.txt → --doctor 의 「기록 자리」가 그 자리로 바뀐다
```

## 나. `--사본치우기`·`--판올리기` 가 아무 말도 안 하던 것 — **네가 본 그대로다**

「stdout 이 비었는데 파일에는 결과가 있다」— 그 관찰이 정확했다. 원인은:

```
줄 안에 「—」(em dash) 가 있는데 cp949 콘솔이 그 글자를 못 찍어
그 자리에서 UnicodeEncodeError → 말이 통째로 사라졌다 (종료값은 0)
```

v0.1.79 에서 막았다고 했는데 **구운 판에서는 그 막이가 안 먹었다** — 소스로만 재고
exe 로 안 쟀다. 이제 세 겹이다: ①막이 ②안 먹으면 새로 감싼다 ③그래도 못 찍으면
**닮은 글자로 바꿔 찍는다**(`—`→`-`, `→`→`->`). 그리고 **못 찍었으면 자국에 남긴다** —
조용히 사라지면 다음에도 못 찾는다.

## 다. `--check` 가 구운 판에서 터지던 것

`inspect.getsource` 와 소스 세기 검사가 **구운 판엔 소스가 없어서** 터졌다.
**「없어서 못 잰 것」과 「재 봤더니 틀린 것」은 다른 말이다.** 이제 건너뛰고 그렇다고 말한다.

```
[잰 것] 구운 exe --check → 「(구운 판이라 소스 검사는 건너뛴다)」 · eb self-check 통과 · 종료값 0
```

## 라. 「VC ↔ VC」 자기 자신과 맞짝 — **결함 맞다**

항목이 하나뿐이면 **자기를 뺀 자리에 아무도 없어서** 프로그램이 자기를 도로 집었다.
**혼자면 이웃은 없다.** 고쳤고 검사로 박았다.

## 마. 「엔진 — 서버 꺼짐」 이 헷갈리던 것

네 말대로 바로 옆에 「★ 원격 열림 :8765」가 떠서 **어느 서버 얘긴지** 모른다.
그 줄은 **글 모델** 얘기였다 → **「엔진 — 글 모델 안 올라옴」** 으로 바꿨다.

# 3. 재 줄 것

## 가. 받자마자
```
sha256 · 제품 버전 0.1.82.0 · 창 「VC」 · 메모리
□ models\ 에 .gguf 를 넣고 창을 켜면 위 띠가 「엔진 — 글 모델 안 올라옴」에서 바뀌나
□ VC.exe --check 가 통과하나 (구운 판 건너뛰기 줄이 보이나)
□ exe 옆 기록자리.txt 로 자리가 바뀌나   ← VC_DATA 말고 이 길로
```

## 나. ★ 흡수 — 지난번에 막힌 자리
```
VC.exe --흡수 <자료폴더>          세어만
□ 본 것 = 들인 것 + 겹친 것 + 버린 것
□ 문지기가 도나 (「비싼 문지기(모델이름) — …」 줄이 뜨나)
VC.exe --흡수 <자료폴더> --쓴다
VC.exe --흡수 <자료폴더>          한 번 더
□ 겹친 것이 전부 · 들인 것 0 · 항목 수 그대로
□ 「제목 (제목).md」 같은 것이 안 생기나
```
★ 네가 만든 10장(빈 파일·앞머리만·같은 내용 둘·한글/괄호 이름)이 **각각 어디로 갔는지**
적어 주면 제일 값지다.

## 다. 흡수 뒤 기준값 (지시서 01 의 표)
```
항목 수 · 연결 수 · 판 적합률 · 빈 항목 · 그물 쌍
--사본치우기 뭉치/치울 것   ← 같은 내용 둘이 잡히나
--판올리기 올릴 것
```

## 라. AI 꺼내기 — **이번엔 큰 자료로**
```
□ 흡수한 창고에서 1단 응답이 몇 자인가 (지난번 작은 글에선 211자)
□ 긴 글 하나를 골라 2단으로 한 토막만 꺼내 보고, 그 글 전체 글자 수와 견줘라
```

## 마. 이건 안 바뀌어야 한다
```
씨앗 글 적합률 1/1 · 외부 수정 반영 · [[링크]] 눌러 가기 · 뒤로 가기 · 목차
--no-server 로 켜면 원격 줄 없음 · 인증 없는 요청 401
```

오너가 실제로 봤다. 이제 안 터진다.
