# 2. 할 것

## 가. ★ 본론 — 죽음 기록 줄
```
□ 0x8001010d 가 찍혀 있던 네 long 창고를 기록 자리로 두고  VC.exe --report
□ 만들어진 VC-진단-*.zip 안 「무엇이 어디.json」 의 「죽음 기록」 줄을 옮겨 적어라
□ ★ 따로 잰다: 그 창고의 vc-죽음.log 를 직접 세어 (Select-String 등)
     「code 0x8001010d」 줄 수 · 그 밖의 「Windows fatal exception」 줄 수 가 그 줄과 같은가
```

## 나. 시험표 — 기본 창고 하나 (새 빈 창고 + fixtures 사본 --쓴다)

## 다. 따로 잰다 (가 말고 1개 더, 네가 고른다) → ★ 여기까지 쓴 보고서를 먼저 올린다

## 라. 판단 몫 — 하나만 · 스크린샷 다섯 장까지
```
□ 창 검색칸에 어느 글에도 없는 말(예: 「어디에도없는말」)을 쳐서
  아래 말풍선이 「…가 든 글은 없어. 뜻으로 가까운 것 N개야」 꼴인가
□ 이어서 있는 말(예: 「검증」)을 쳐서 「… 관련 N개야」 꼴인가
```
검색칸은 `Ctrl+O` 로 가라 — 화면 조작 도구 누름이 딴 창에 먹힐 수 있다.
