# 급함 — v0.1.93 `--no-ui` 뜻 검색이 끝까지 이어지지 않음

- [잰 것] 분리 기록자리에서 `VC.exe --no-ui`를 실행했고 최상위 창 없이 서버 프로세스가 돌았다.
- [잰 것] 서버가 돈 뒤 새 글 `안개 항로 안내 실험.md`를 넣고 1분 넘게 기다렸다.
- [잰 것] `notes_index.db`의 `vectors` 행은 1개, 벡터 바이트 길이는 768이었다. `--doctor`도 `항목 수 1 · 뜻 벡터 수 1 · 아직 못 만든 벡터 0`이라고 적었다.
- [잰 것] Bearer `GET /eb/v1/memory/search`에서 본문에 그대로 있는 한 단어 `등대`로 물으면 `안개 항로 안내 실험` 1건이 나왔다.
- [잰 것] 같은 API에 글의 뜻을 바꿔 쓴 질문을 넣으면 기대는 그 글 1건인데 실제는 모두 0건이었다. 첫 시도부터 계속 0건이었다.
  - `야간 항해를 돕는 해안 표지`
  - `안개 속 등대가 선박을 인도한다`
  - `짙은 안개 속에서 등대 빛이 배가 안전한 뱃길을 찾게 이끈다`
  - 영어 `lighthouse`
- [잰 것] 글을 더 길게 보강한 뒤 다시 1분 넘게 기다려도 같은 결과였다.
- [짐작이다] 벡터 생성은 됐지만 이 API 검색 결과에 뜻 벡터 경로가 적용되지 않거나, 임계값 때문에 전부 빠지는 것으로 보인다. 원인은 코드로 확인하지 않았다.

프로그램 코드는 고치지 않았다. 토큰 값은 기록하지 않았다.
