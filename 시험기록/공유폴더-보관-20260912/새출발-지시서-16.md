```

2) 소스로 재니 matmul 에서 통째로 터짐 (768 대 384)
   → 구운 판이 만든 벡터를 딴 크기 모델로 읽었다. 크기가 바뀌면 옛 벡터를 버리는 코드는
     있었는데 **화면 쪽에서만** 불렀다 — 명령줄 길에는 방어가 없었다
```

# 2. 할 것

## 가. ★ 본론 — 재는 자리가 비면 숫자가 그렇게 말하나
```
□ 새 빈 창고를 만들고 글 없이 --찾기점수 <아무 물음파일>
   → 머리글에 「항목 0개」 가 찍히나 (0/20 만 보이면 안 된다)
□ 네 long 창고에서 --찾기점수 (물음 파일은 아래 3장 참고)
   → 머리글의 「항목 N개 · 아직 못 만든 벡터 M개」 를 그대로 옮겨 적어라
□ 벡터가 덜 찼으면 창을 몇 분 띄워 채운 뒤 다시 재고, 두 값을 나란히 적어라
   (이 둘이 다르면 「못 찾는다」가 아니라 「덜 익었다」는 뜻이다)
```

## 나. 딴 크기 모델을 끼워도 안 터지나
```
□ 창을 띄워 모델 칸에서 뜻 모델을 바꿀 수 있으면 바꿔 보고, 검색이 터지지 않는지
□ 못 바꾸면 「못 쟀다」로 적어라 — 억지로 파일을 바꾸지 마라
```

# 3. 곁들임 — 물음 파일 꼴
