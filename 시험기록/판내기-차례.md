# 판 하나 내는 차례 (2026-09-13)

오늘 열 번 넘게 냈다. 매번 같은 것을 손으로 해서 **두 번 헛디뎠다**(판번호가 안 올라간 채
태그를 달았고, 굽기를 겹쳐 두 판을 날렸다). 그 자리는 다 막이를 걸었지만 차례는 적어 둔다.

```
0) ★ **고칠 것을 모은다.** 하나 고치고 굽고를 되풀이하지 마라(오너 2026-09-13).
   굽기 한 번이 몇 분이고, 물려서 잣대까지 돌리면 그보다 길다. **한 묶음에 한 판**이다
1) 묶음을 다 고친다
2) VC.exe --모두검사        ← 스물아홉 개가 다 돈다(74~85초). 이것만 돌리면 된다
   ★ 검사를 새로 넣었으면 **되돌려 터지는지** 본다. 안 터지면 죽은 검사다
3) ★ **굽기 전에 소스로 한 바퀴 돈다** — 굽지 않고도 거의 다 잡힌다
   python pc\eb.py --no-ui            (VC_DATA 를 실무 창고로 두고, 뜨는 데 25초)
   시험기록\잣대-한바퀴.py · 잣대-덮어쓰기보호.py
   여기서 터지면 굽는 시간을 안 버린다
4) pcuild.ps1            ← **묶음당 한 번.** 리다이렉트(`2>$null`·`> 파일`)를 붙이지 마라
                             겹쳐 굽지 마라 — 자물쇠가 막지만 기다리는 게 낫다
5) 구운 판에서는 **구워야만 나는 것**만 본다
   --doctor 의 판 줄          판 번호가 올라갔나
   창 띄우기                  창 「VC」 · 정상 종료 · 죽음 기록 0줄
   잣대 한 바퀴 한 번          작은 창고가 우연히 통과시키는 것을 여기서 잡는다
   (cp949 · 상대경로 · --noconsole 은 소스에서는 안 난다. 그래서 이 단계가 남는다)
6) 현재상태.md 의 「지금 판」 덩이를 갈고 커밋 · 태그
7) paths.VERSION 을 올린다   ← 안 올리면 다음 `--check` 가 「이 판은 나갔다」로 터진다
```

## 밟은 함정들 (다 막이를 걸었다)

| 함정 | 막이 |
|---|---|
| 판번호가 안 올라간 채 태그 | `v<VERSION>` 태그가 있으면 `paths --check` 가 터진다 |
| 굽기를 겹쳐 둘 다 깨짐 | `%TEMP%\vc-build.lock` 자물쇠 |
| 커밋 메시지의 한글·따옴표가 셸을 깸 | **늘 파일로 넘긴다**(`git commit -F`) |
| 자체점검을 빠뜨림 | `--모두검사` 한 줄 |
| 안내와 실제 길이 어긋남 | 좁히는 이름이 안내에 없으면 터진다 |
