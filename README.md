# VC

**공개 배포 · v0.5.31**

기록을 로컬에 저장하고 의미 검색과 근거를 붙인 답변으로 다시 찾는 개인 AI 작업공간입니다. 여러 기기에서 같은 기록 공간을 이용합니다.

**[다운로드](https://github.com/VULCAN-HUB/VC/releases/tag/v0.5.31)** · **[사용 안내](#사용법)**

제작: **Unknown** · [홈페이지](https://vulcan-hub.github.io/) · [YouTube](https://www.youtube.com/@unknown8563)

## 기능

- 로컬 AI 모델로 기록을 검색하고 근거를 붙여 답변합니다.
- 주소로 자료를 모으고 그래프에서 기록의 연결을 확인합니다.
- 한 기기를 메인으로 두고 다른 PC와 연결합니다.
- 앱 안에서 AI 모델을 받고 새 버전 안내를 확인합니다.

## 요구사항과 상태

| 항목 | 내용 |
|---|---|
| 실행 환경 | Windows 또는 macOS · 앱 내 AI 모델 별도 다운로드 |
| 배포 형태 | Windows 설치형 EXE · macOS DMG |

v0.5.31 공개 배포본입니다. 공개 문서에 최소 하드웨어 사양과 기기별 검증 범위는 명시되어 있지 않습니다. 기록과 AI 모델은 기본 포함되지 않습니다.

## 사용법

| | 파일 |
|---|---|
| 윈도우 | `VC-Setup-<판>.exe` — 받아서 실행하면 설치된다 |
| 맥 | `VC-mac-<판>.dmg` — 열고 VC 를 응용 프로그램으로 끌어다 놓는다 |

한 번 깔면 그다음은 **VC 가 새 판을 알려 준다.**

### 처음 실행

- **기록도 모델도 들어 있지 않다.** 빈 창고로 시작한다.
- AI 모델은 VC 안에서 받는다 — 어디를 눌러야 하는지 VC 가 말해 준다.
- 기록은 `문서/VC` 폴더에 `.md` 글로 쌓인다. 다른 편집기로 열어도 된다.

### 기록과 기기 연결

- **찾기 칸이 곧 말하는 칸이다.** 낱말을 치면 찾고, 물음표로 끝내면 창고를 뒤져 근거를 달아 답한다.
- **주소를 붙여 넣으면 모아 둔다.** 정리는 VC 가 뒤에서 한다.
- **그래프**에서 글과 글이 어떻게 이어지는지 본다. 기계마다 제 행성으로 나뉜다.
- **여러 기계**: 한 기계를 메인으로 두고, 다른 PC 는 쪽지 한 줄로 붙인다. 폰 앱도 같은 창고를 본다.
