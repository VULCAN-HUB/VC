## 지금 되는 것

```bash
cd pc
python -X utf8 eb.py        # 이것 하나만. 서버 + 화면이 같이 뜬다
```

두 번 실행해도 안 죽는다 — 서버가 이미 떠 있으면 그쪽에 붙는다(폰이 이미 그쪽과
이야기하고 있을 수 있다). `--no-ui`면 서버만, `--no-server`면 화면만.

따로 띄우려면:

```bash
python -X utf8 server.py    # 서버만
python -X utf8 demo.py      # 키보드로 이비 부르기 (개발용)
```

`demo.py`에서 `이거 뭐야`를 세 번 치고 `:분석` → `:제안` → `:승인 0`을 하면,
이비가 자기 낭비를 찾아내 고치는 전 과정을 볼 수 있다.

## 구성

| 파일 | 역할 |
|---|---|
| `pc/eb.py` | **실행 진입점.** 서버 + 화면을 같이 띄운다 |
| `protocol.md` | 폰↔PC 규격. 추론은 OpenAI 호환을 그대로 쓴다 |
| `pc/eb_protocol.py` | 메시지 정의. 코틀린 쪽도 여기 맞춘다 |
| `pc/backends.py` | 백엔드 어댑터 3벌 (OpenAI 호환·클로드·제미나이) |
| `pc/store.py` | 학습 로그·제안 (SQLite) |
| `pc/notes.py` | 항목 저장소. 마크다운이 원본, SQLite는 인덱스 |
| `pc/engine.py` | **이비 자체 엔진.** GGUF를 프로세스 안에서 돌린다. Ollama 안 쓴다 |
| `pc/voice.py` | **귀와 입.** 말로 부르고 말로 답한다 |
| `pc/brain.py` | **1단 온디바이스 모델.** 어느 모듈을 부를지 고르고, 확신 없으면 안 고른다 |
| `pc/modules.py` | 이비가 부리는 부품 목록 |
| `pc/product_search.py` | **첫 진짜 부품.** 사진 → 식별. 확신 모자라면 위 단계로 올린다 |
| `pc/remote.py` | **외부 PC 원격 접속.** QR을 폰이 찍어야 길이 열린다 |
| `pc/skills.py` | 선언적 스킬 + 규칙 기반 분석기 |
| `pc/orchestrator.py` | **폰으로 이식될 참조 구현.** 모듈 선택·라우팅·전경배경·계측 |
| `pc/server.py` | 폰이 붙는 HTTP 서버 |
| `pc/demo.py` | 키보드로 전 경로를 돌려보는 데모 |
| `pc/ui.py` | 그래프 화면. 말할 때 항목이 옅은 하늘색으로 밝아진다 |

각 파일은 자체검증을 들고 있다. 전부 돌리려면:

```bash
cd pc
for f in eb_protocol backends brain store notes orchestrator skills; do python -X utf8 $f.py; done
python -X utf8 server.py --check
python -X utf8 ui.py --check
```

## 라우팅 3단 (결정 11)

```
1단 규칙   트리거가 하나만 걸리면 그대로 실행
2단 모델   brain.py — 문자 n-gram 유사도. 띄어쓰기·어미가 달라도 같은 말로 본다
3단 되묻기 최저점(0.34) 미만이거나 1·2등 격차(0.07) 미만이면 고르지 않는다
```

되묻던 표현은 제안으로 올라오고, 사용자가 고르면 그 모듈이 그 말을 배운다 —
`데모`에서 `:판정 <말>` 로 점수를 직접 볼 수 있다.

임베딩 모델을 끼우려면 `brain.EmbedBrain(embed)` 에 `list[str] -> list[list[float]]`
하나만 넘기면 된다. 폰은 ONNX Runtime, PC는 무엇이든. 모델이 터지면 n-gram으로 내려간다.

## 외부 PC에서 쓰기 (사용자마다 각자 자기 서버PC로)

사용자는 자기 서버PC와 자기 폰을 갖는다. 밖에 나가 아무 PC에서나 자기 이비를 쓴다.

**경로 A — 폰 중계 (제3자 0, 기본):**

```
외부 PC를 폰 핫스팟/같은 와이파이에 물림
  → 브라우저로 폰 주소 (핫스팟이면 대개 192.168.43.1:8770)
  → 외부 PC 화면에 네 자리, 폰에도 대기 알림
  → 눈으로 대조하고 폰에서 승인
  → 외부 PC ↔ 폰 ↔ 서버PC. 폰은 배달만 하고 내용은 안 본다
  → 끊으면 토큰·세션 삭제
```

NAT를 뚫는 게 아니라 **피한다**. 폰이 만든 로컬망 안에서는 폰이 게이트웨이다.
중계 서버도 시그널링 서버도 필요 없다.

**경로 B — P2P 직결 (미구현):** 와이파이를 못 바꾸는 PC용. WebRTC로 브라우저↔서버PC를
직결하고 주소 교환만 외부를 쓴다. 내용은 어느 경우에도 제3자를 안 지난다.

지키는 선 — 승인 없으면 상태 조회 외 전부 401 / 2분 만료 / 코드 3회 틀리면 세션 폐기 /
토큰은 처음 쓴 IP에 고정 / 30분 유휴 시 해제 / 원격은 지시·조회·내려받기만
(스킬 승인·설정 변경은 폰과 내 PC에서만).

폰은 자기 페어링 토큰을 외부 PC에 넘기지 않는다. 넘기면 외부 PC가 폰 권한을 그대로 얻는다.
결과물은 `data/artifacts/`에 남아 외부 PC·내 PC 양쪽에서 내려받는다.

## 되돌리지 않는 원칙

- **얼굴 식별 없음.** 자동 촬영 프레임은 분석·기록보다 **앞서** 모자이크한다.
- **폰에서 자동 생성 코드를 실행하지 않는다.** 코드 실행은 PC에서만, 승인·샌드박스·감사 로그와 함께.
- **자동 생성 스킬은 자동 적용하지 않는다.** 제안 → 승인 → 버전 기록 → 되돌리기.
- **확신 없이 실행하지 않는다.** 모호하면 되묻는다.
- **PC가 없어도 이비는 동작한다.** PC는 켜져 있으면 더 똑똑해지는 관계다.

## 말로 부르기

```bash
cd pc
python -X utf8 demo.py     # 그다음 :음성
```

`"이비, 볼륨 올려줘"` 라고 말하면 된다. 호출어만 부르면 "응" 하고 기다린다 —
**"이비"는 2음절이라 오인식이 잦아서**(이비인후과·이비에스) 호출어만으로는 실행하지 않는다.

받을 게 없다. 받아쓰기는 `faster-whisper`(base, CPU), 목소리는 OS에 이미 있는 것을 쓴다
(윈도우 한국어 Heami / 맥 `say`).

실측: 한 문장 받아쓰기 **0.8~0.9초**. 받아쓰기가 `올려줘`를 `볼려줘`로 흘려도
라우팅은 0.92로 안 흔들린다 — 문자 n-gram이 어미 잡음을 견딘다(결정 31).

말하는 동안에는 듣지 않는다. 자기 목소리를 다시 받아쓰면 혼자 대화가 이어진다.

## 엔진 (결정 36)

**이비가 모델을 직접 올리고 내린다.** Ollama를 따로 깔지 않는다. GGUF 파일을
`models/`에 넣으면 파일명(확장자 뺀 것)이 곧 모델 이름이다.

```json
{"backend": {"kind": "local", "model_dir": "../models"}}
```

한 번에 한 모델만 올린다 — 4GB짜리 GPU에서 둘을 올리면 둘 다 못 쓴다. 다른 모델을
부르면 먼저 내리고 올리고, 10분 놀면 저절로 내려간다.

실측(Qwen2.5-1.5B-Instruct Q4, CPU): 첫 호출 3.8초(로딩 포함) → **두 번째 0.5초**.
상주 제어가 있고 없고의 차이가 7.6배다.

전경 지시가 배경 분석을 앞지른다(결정 21이 큐까지 내려간다).

클라우드로 바꾸려면 `kind`를 `anthropic`·`gemini`·`openai_compatible`로. 어댑터 3벌은
그대로 살아 있다(결정 3, BYO 키).

## 제품 검색 쓰려면

**비전 모델**이 있어야 실제로 답한다. 글자 모델로는 사진을 못 본다.
GGUF 비전 모델은 본체와 `mmproj` 짝이 함께 있어야 하고, 이비는 파일 이름으로 짝을 찾는다.

```
models/qwen2.5-vl-3b.gguf          ← 본체
models/qwen2.5-vl-3b.mmproj.gguf   ← 짝. 이름 앞부분이 같아야 한다
```

```json
{"vision_model": "qwen2.5-vl-3b"}
```

짝이 없으면 `not_vision_model`로 막는다. **글자 모델은 사진을 조용히 무시하고 그럴듯한
답을 지어내는데, 그게 제일 나쁜 실패다** — 사용자가 틀렸다는 걸 알 방법이 없다.

## GPU 쓰려면

CUDA 휠 + CUDA 런타임이 필요하다. **CUDA Toolkit을 시스템에 설치하지 않아도 된다.**

```bash
pip install llama-cpp-python --prefer-binary --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cu124
pip install nvidia-cuda-runtime-cu12 nvidia-cublas-cu12
```

이비가 `nvidia-*` 패키지 안의 DLL 폴더를 **프로세스에만** 등록한다. 사용자 PATH는
건드리지 않는다 — 설치형 앱이 시스템 환경변수를 고치면 지우기도 어렵고 다른 프로그램에
영향이 간다.

윈도우에서 `pip install llama-cpp-python`이 소스 빌드로 가면 MAX_PATH 한계로 깨진다.
`--prefer-binary`와 휠 인덱스를 꼭 붙일 것.

시세는 아직 안 붙였다. 가격 조회는 제공자마다 규격도 약관도 달라 따로 정해야 한다.
