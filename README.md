# VC

로컬 우선 개인 AI 작업공간. 20년 치 업무·기획·자료를 담아 두고, **낱말이 기억 안 나도**
꺼내 쓴다. 기록은 그냥 마크다운 파일이라 옵시디언으로 같은 폴더를 그대로 열 수 있다.

Windows 10/11 64비트 · 설치 과정 없음 · 인터넷 없이 돈다.

## 받기

[릴리스](../../releases/latest)에서 `VC.zip`을 받아 압축을 풀고 `VC.exe`를 실행한다.
**폴더 통째로** 옮겨야 한다 — exe 하나만 빼내면 안 돈다.

기록은 `문서\VC\`에 생긴다.

## 문제가 생기면

우리는 그쪽 PC 화면을 못 본다. 그래서 프로그램이 스스로 남긴다.

| 하는 일 | 어떻게 |
|---|---|
| 무엇을 어디서 찾는지 본다 | `VC.exe --doctor` |
| **진단 묶음을 만든다** | `VC.exe --report` 또는 화면에서 `⋯` → 문제 알리기 |

진단 묶음(`VC-진단-….zip`) **하나만 보내면 된다.** 안에 든 것:

- 무엇이 어디 있는지 (윈도우 판, 모델 자리, 항목 수)
- 켜고 끈 자국 — 죽어도 어디까지 갔는지 보인다
- **죽음 기록** — 파이썬 오류로 안 잡히는 죽음까지 담긴다
- 설정 (토큰은 지운 채로)

**안 담기는 것**: 기록 내용, 파일 이름, 사용자 이름.

## 받은 파일이 맞는지

```powershell
Get-FileHash VC.zip -Algorithm SHA256
```

`VC.zip.sha256`의 값과 같아야 한다. 백신이 막았을 때 신고 근거도 된다.

## 백신이 막으면

압축을 풀어 쓰는 폴더형(onedir)이라 자가추출을 안 하고, UPX 압축도 안 쓴다 —
오탐을 부르는 두 가지를 다 피했다. 그래도 막히면 위 SHA-256과 함께 알려 달라.

## 안 되는 것 (받기 전에 알아 둘 것)

- **다른 PC에서 처음 돌려 보는 판이다.** 만든 PC에서는 다 되지만 그쪽은 아직 모른다.
- 탭이 없다 — 곁에 띄우는 판은 읽기만 된다.
- 캔버스·플러그인·커뮤니티 테마·폰 앱 없음.
- 말로 시켜 실제로 되는 것은 소리 크기 조절뿐이다.
- 문서 안에서 찾기(`Ctrl+F`)가 전체 검색으로 간다.
