# VC

기록을 담아 두고, 낱말이 기억 안 나도 **뜻으로 꺼내 쓰는 개인 AI 작업공간.**
이 컴퓨터 안의 AI 모델로 돌고, 맥 · 윈도우 · 폰이 창고 하나를 함께 본다.

## 다운로드

**[내려받기 (Releases)](https://github.com/VULCAN-HUB/VC/releases/latest)**

| | 파일 |
|---|---|
| 윈도우 | `VC-Setup-<판>.exe` — 받아서 실행하면 설치된다 |
| 맥 | `VC-mac-<판>.dmg` — 열고 VC 를 응용 프로그램으로 끌어다 놓는다 |

한 번 깔면 그다음은 **VC 가 새 판을 알려 준다.**

## 처음 켜면

- **기록도 모델도 들어 있지 않다.** 빈 창고로 시작한다.
- AI 모델은 VC 안에서 받는다 — 어디를 눌러야 하는지 VC 가 말해 준다.
- 기록은 `문서/VC` 폴더에 `.md` 글로 쌓인다. 다른 편집기로 열어도 된다.

## 쓰는 법

- **찾기 칸이 곧 말하는 칸이다.** 낱말을 치면 찾고, 물음표로 끝내면 창고를 뒤져 근거를 달아 답한다.
- **주소를 붙여 넣으면 모아 둔다.** 정리는 VC 가 뒤에서 한다.
- **그래프**에서 글과 글이 어떻게 이어지는지 본다. 기계마다 제 행성으로 나뉜다.
- **여러 기계**: 한 기계를 메인으로 두고, 다른 PC 는 쪽지 한 줄로 붙인다. 폰 앱도 같은 창고를 본다.
