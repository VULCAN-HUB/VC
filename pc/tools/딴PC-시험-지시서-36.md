# VC v0.1.77 — D-01·D-02 고쳤다. **네 「조건부 보류」의 근거를 없앴다**

네 완료보고서를 읽었다. **판정이 옳다** — D-01 은 「알려진 제약」으로 넘길 것이 아니라
**고칠 것**이었다. 고쳤다.

# 1. D-01 (Critical) — 원인을 고쳤다

★ **네 말이 정확하다:**

> `--사본치우기` 는 증상을 치우는 기능이고, 원인은 아직 살아 있다.
> 지금 치워도 다시 흡수하면 다시 쌓인다.

원인은 한 줄이었다 — **흡수의 겹침 판정이 「이번 판 안」만 본다.**

```
본지문: set[str] = set()      ← 매번 빈 채로 시작한다
```

기록에 **이미 든 글은 아예 안 봤다.** 자료가 없어서가 아니라 **안 본 것**이라는
네 말 그대로다. 이제 흡수가 **기록에 든 글의 지문을 먼저 읽고** 시작한다.

```
[잰 것] 같은 폴더를 두 번 --흡수 --쓴다
        1차 : 본 것 1 · 들인 것 1 · 겹친 것 0 · 1개 썼다 · 항목 1
        2차 : 본 것 1 · 들인 것 0 · **겹친 것 1** · **0개 썼다** · **항목 1**
```

★ **이게 네 기록 12.2%(388뭉치)를 만든 그 원인이다.** 이제 안 쌓인다.

※ 곁가지로 짚어 준 `제목 (제목).md` — 그건 **겹칠 때 출처를 덧붙이는 규칙**이
  제목과 출처가 같아서 겹쳐 보인 것이다. 겹침이 안 생기면 이 이름도 안 생긴다.

# 2. D-02 (Major) — 셈 약속을 되살렸다

**조각이 하나도 안 나오는 파일이 셈에서 통째로 빠졌다.** 파일 셋을 넣었는데 본 것이 2였다.

```
[잰 것] 빈 파일 · 앞머리만 · 이진 쓰레기 셋을 넣으면
        본 것 3 · 들인 것 0 · 겹친 것 0 · 버린 것 3
        **본 것 = 들인 것 + 겹친 것 + 버린 것** ✓
```

# 3. 짝짓기 — 네가 짚은 「진짜 사본도 놓친다」도 고쳤다

네 갈라내기가 옳았다:

```
본문 같음 · 제목 다름   → 사본 아님   (활동두번째 · 줄이 겹친다 · 띄우기시험)
본문 같음 · 제목도 같음 → **진짜 사본** (8월 회의록 ×3 — 본문 20자)
```

이제 **짧은 것은 제목 밑동까지 같을 때만** 짝을 짓는다. 밑동은 겹칠 때 붙는
꼬리(` 2`·` (출처)`)를 뗀 것이다 — 「8월 회의록」·「8월 회의록 2」는 같은 밑동이다.

```
[잰 것] 위 여섯을 한 자리에 넣으면 → 뭉치 1개 · 치울 것 2장
        치움: 8월 회의록 2 · 8월 회의록 3    남길 것: 8월 회의록
        (제목 다른 셋은 안 묶인다)
```
