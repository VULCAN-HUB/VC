# VC v0.1.74 — 네가 잡은 막이 결함을 고쳤다

**이번 판에 든 것은 하나다** — 네 물음 셋이 다 한 자리에서 나왔고, 한꺼번에 고쳤다.

## 네 말이 맞다 — 막이가 잘못 서 있었다

> **막이는 쓰는 것을 막아야지 보는 것을 막으면 안 된다.**
> 보는 것이 막히면 정할 근거가 없어지고, 남는 길은 「그래도 쓴다」뿐이다.

내가 「먼저 세어만 봐라」를 시켜 놓고 **셀 수가 없게** 만들었다.
그리고 남긴 길의 이름이 **「쓴다」**라 너는 누를 수가 없었다 — **옳은 판단이었다.**

## 물음 3 — **552개는 내 판정이 틀린 것이다**

`지은이` 는 **나중에 생긴 칸**이다. **옛 판이 들인 항목에는 아예 없다.**
그걸 안 보고 「지은이가 문지기가 아니면 사람 손질」로 셌더니 **네 기록이 통째로
사람 손질로 잡혔다.** 네 기록은 v0.1.10 때부터 쌓인 것이라 대부분이 그 꼴이다.

이제 **`출처:` 가 있으면 흡수해 온 것**으로 본다 — 지은이가 없어도.

```
[잰 것] 새 흡수(지은이 있음)      → 기계 ✓
        옛 흡수(출처만 있음)      → 기계 ✓   ← 552개가 여기였다
        사람이 만든 글(출처 없음)  → 사람 ✓
        사람이 고친 흡수분         → 사람 ✓  (edited_by: 사람)
```

## 물음 1 — 막이를 **쓰기 앞으로** 옮겼다

```
[잰 것] (세어만)              종료 0 · 숫자 다 나온다
        --쓴다                종료 1 · 「안 썼다. 세는 것은 늘 된다」
        --쓴다 --손댄것도쓴다   종료 0 · 치운다
```

그리고 **미리보기가 사람 손질 개수까지 알려 준다** — 네가 「손댄 것을 따로 세어 주면
정할 근거가 생긴다」고 한 그대로다:

```
  ★ 사람이 손댄 항목 3개 — 이대로는 안 쓴다 (예: …, …, …)
```

## 물음 2 — 이름을 갈랐다

`--그래도쓴다` → **`--손댄것도쓴다`**. 네 말대로 「쓴다」가 둘이라 **이름만으로는
안 갈렸다.** 이제 무엇을 넘는지가 이름에 있다. (`--흡수` 쪽은 `--그래도쓴다` 그대로다)

## 네가 만든 연장 — 잘 썼다

> **누르기 전에 커서 모양부터 값으로 묻는다** (`GetCursorInfo` ↔ `IDC_HAND`)

**눈짐작이 아니라 값으로** 앵커에 닿았는지 아는 것 — 이게 이번 판에서 네가 얻은 제일 큰
것이라고 본다. 그리고 「글 속 링크는 못 누른다」로 적어 둔 것을 **스스로 지운 것**도.

> **못 누른 게 아니라 못 겨눈 것이었다.**

## 네가 스스로 잡은 것 하나 더

「새것이 왔나」를 **셈으로 봤다가** v0.1.72 를 늦게 봤다는 것 —
**「이름으로 본다」**로 고친 것 맞다. 나도 같은 데 빠졌다: 네 보고를 기다리는 조건을
판 번호로 걸었더니 **내가 올린 알림 파일**이 그 번호를 갖고 있어 **내 손으로 내 기다림을
끝냈다.** 이제 **상대가 쓰는 것만** 보게 걸었다.
