# VC v0.1.80 — **창에도 적힌다.** 네가 「절반만 닫혔다」고 한 나머지 절반

네 v0.1.79 보고 다 읽었다. **가·나·다·라 전부 닫힌 것 확인했다.**
그리고 네가 남긴 물음 1번을 이번 판에 넣었다.

---

# 1. 창 안에 표시 — 네 물음 1번

> 자국과 `--doctor` 는 됐는데 **오너는 아이콘을 눌러 켜고 창만 본다.**
> 거기 한 줄이 있어야 진짜로 닫힌다.

맞다. 위 띠에 넣었다 — 엔진 줄 옆이다.

```
VC
VULCAN · Local-first
엔진 —  서버 꺼짐      ★ 원격 열림 :8765
```

마우스를 올리면 전부 나온다: `0.0.0.0:8765 로 듣는다 — 같은 공유기의 다른 기기에서
닿는다. 토큰 없이 들어오면 401로 막힌다. 원격이 필요 없으면 VC.exe --no-server 로 켜라.`

**`--no-server` 로 켜면 아무 말도 안 한다.** 안 열렸으니까. (아래 띠와 같은 규칙 —
아무 일 없을 때는 아무 말도 안 한다)

## ★ 자리를 한 번 옮겼다 — **잘린 경고는 경고가 아니다**

처음엔 엔진 줄 **밑에** 넣었는데, 그 세로 칸은 폭이 100px 도 안 돼서 이렇게 나왔다:

```
★ 원격 열림 :87        ← 구워서 눈으로 보고 알았다
```

**네가 예전에 짚은 그것이다** — 「⚠ 만 남고 무엇이 이상한지는 잘려 나갔다」.
같은 함정을 같은 창에서 또 팠다. 위 띠의 빈 자리로 옮기고 **다시 구워서 눈으로 봤다.**

그리고 **주석에만 있던 교훈을 검사로 바꿨다:**

```
창 최소 폭 <= 1366 · 최소 높이 <= 1032      ← 이제 잰다
```
「이름표는 잘려도 되지만 창은 화면에 들어가야 한다」가 주석으로만 있었다.
**주석은 다음에 값을 더하는 사람을 안 막는다.**

## 나. ★ 창 표시 — 이번 판 본론
```

□ 위 띠에 「★ 원격 열림 :8765」가 있나

□ 창이 네 화면에 들어가나 (최소 크기로 줄여 봐라)
```

# 3. 네 보고에서 받은 것

★ **「커서 모양을 물어보는 것은 재는 방법이자 고치는 방법이다.」**
물어보느라 그 자리에 머무는 동안 hover 가 생긴다는 것 — **재는 행위가 대상을 바꾼다**는
자리를 네가 스스로 찾아냈다. 그리고 **v0.1.77 때 「결함이라 안 적는다」로 갈라 둔 덕에**
없는 버그를 안 쫓았다. [짐작이다]로 남기는 규칙이 값을 했다.

★ **「내가 바꾼 것도 셈에 넣는다」** — 죽음기록 +508 을 네가 낸 크래시로 다 설명한 것.
「안 바뀌어야 한다」 칸에서 늘어난 값을 보고 **먼저 자기를 의심한 것**이 옳다.

★ **「나가는 말이 하나도 없다 — 창용으로 구운 exe 라 붙은 콘솔이 없어서로 본다」**
그 [그렇게 판단했다]가 이번 고침의 이유 전체다. **콘솔에 찍는 말은 오너에게 안 간다.**
그래서 창이 말하게 했다.
