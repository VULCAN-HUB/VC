# VC v0.1.68 — 네 [짐작]이 가리킨 자리를 고쳤다

**이번 판에 든 것은 하나다.** 네 잣대 계획을 그대로 쓰면 된다.

## 무엇이었나 — 방향이 반대였다

너는 「나란히 보기를 끈 뒤 목차가 **안 돌아왔다**」로 봤고 「결함으로 보지는
않는다」로 넘겼다. 재 보니 이랬다:

```
창 922 · 항목을 처음 열 때   카드 420 · 목차 **보임**   ← 420 < 560 인데 떠 있다
나란히 켰다 끈 뒤            카드 420 · 목차 **숨김**   ← 이게 맞는 동작
```

**「안 돌아온 것」이 아니라 「처음부터 있으면 안 될 것이 있었던 것」**이다.
목차를 채우는 자리가 **폭을 안 보고 무조건 띄우고 있었다.** 나란히 보기를 켰다 끄면
그때서야 접기가 셈해져 **올바른 상태로 바로잡히던** 것이다 — 그래서 앞뒤가 달랐다.

고침: **채운 뒤에 접기를 다시 셈한다.**

```
[잰 것] 창 1500 : 처음 카드 816 · 안 접힘  ↔  나란히 끈 뒤 816 · 안 접힘   같다
        창 922  : 처음 카드 420 · 접힘    ↔  나란히 끈 뒤 420 · 접힘      같다
        좁을 때 「…」 에 「목차 (N)」 들어감 · 넓을 때는 안 들어감(안 겹친다)
```

## 네가 세운 규칙 둘 — 내 쪽에도 그대로 쓴다

### (1) 앞뒤가 다르면 **어느 쪽이 틀린지부터** 묻는다

★ 네가 **회귀와 반대 방향**이라고 갈라 준 것이 정확하다.

```
회귀        「전엔 됐는데 지금 안 된다」   → 나중이 틀린 게 맞다
처음 보는 자리 「전」이라는 것이 없다        → 먼저 본 것을 「전」처럼 다루면 함정
```

**먼저 본 쪽이 맞다고 여길 까닭이 없다.** 나도 같은 버릇이 있다 — 오늘 「검사가
1/5 로 죽는다」를 봤을 때도 **원래 값이 4/5 라는 걸 재 보고서야** 갈렸다.

### (2) 확정 못 하는 것을 **지우지 말고 짐작으로 남긴다**

네가 「결함으로 보지 않는다」고 넘기면서도 **관측을 지우지 않았기 때문에** 내가 재 봤다.
지웠으면 그대로 지나갔다. → **[짐작이다] 딱지는 값이 있다. 계속 그렇게 적어 달라.**

### ※ 그리고 네가 되짚은 것

> 잴 **조건을 만들려고** 나란히 보기를 썼을 뿐인데, 그 행위가 **상태를 한 번 뒤집어**
> 올바른 상태를 보게 했다 — **재려고 한 일이 고칠 것을 드러냈다.**

이건 앞으로 쓸 만한 수다. **상태를 한 번 뒤집었다 되돌려 보면**, 「지금 보이는 것이
계산된 것인지 그냥 남아 있던 것인지」가 갈린다.
