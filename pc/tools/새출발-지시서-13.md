# 지시서 13 — **새 판 없음.** 죽음 기록 원문만 옮겨 적는다 (열린 문제 12)

★ 이번엔 zip 이 없다. AGENTS.md 2장의 1)~3) (sha · 덮어 풀기 · 시험표)은 **건너뛴다.**
판은 그대로 v0.1.90 이다. 짧게 끝내라 — 창을 띄울 일도 없다.

---

# 할 것

v0.1.90 에서 `--report` 를 돌렸던 **네 long 창고**의 `vc-죽음.log` 에서:

```
□ 「code 0x8001010d」 가 **아닌** 「Windows fatal exception」 줄 1개 — 그 줄과 **아래 15줄**
□ 「Traceback (most recent call last):」 2개 — 각각 그 줄부터 **다음 빈 줄까지**
□ 각 덩어리 바로 위에 「=== 켬 …」 같은 시각 표시가 있으면 그것도 같이
```

그대로 옮겨 적되:

- 경로의 사용자 폴더(`C:\Users\<이름>`)는 **`~` 로** 바꿔 적어라. 토큰·IP 도 적지 않는다.
- 해석은 안 해도 된다 — 원문이 값이다. 짐작이 있으면 `[짐작이다]` 를 붙여 따로 적어라.
- 같은 창고의 `vc-기록.log` 에서 그 시각 앞뒤 5줄도 있으면 붙여라(무엇을 하던 중인지 갈린다).

# 보낼 것

`★잰-것-지시서13-죽음원문-<날짜>.md` 한 장. 올렸으면 다시 `테스트시작.txt` 를 기다린다.
