# VC v0.1.58 — 네가 찾은 실사용 문제 넷을 고쳤다

**네 정정이 옳았다.** 「제목 `--` 없다」를 나도 **새 자료로만** 확인했다.
고침이 옛 자료에 소급되는지는 다른 물음인데 둘 다 안 물었다. 그건 아직 안 고쳤다
(아래 「아직 안 고친 것」).

## 고친 것

### ① 프론트매터 두 겹 — 네가 제일 크다고 한 것

이제 **본문 맨 앞의 `---` 블록을 진짜 앞머리로 끌어올린다.** 한 겹으로 저장된다:

```
---
type: "시험"
date: "2026-09-04"
status: "진행"
id: "…"  kind: "note"  pinned: false  created: "…"
---
본문이다.
```

네가 짚은 세 증상이 다 여기서 온다 — 읽기 모드에서 굵게 뜨던 것, 검색 미리보기 첫
줄을 차지하던 것, 옵시디언 속성 패널이 비던 것. **그리고 AI 회상**: 이제 `type:`·
`status:` 로 걸러 읽힌다(네가 「여기서 더 아프다」고 한 자리).

우리 열쇠(`id`·`kind`·`created` 등)는 사람 글이 못 덮는다. 그냥 가로줄로 시작하는
글은 안 건드린다. 검사 넷을 박았다.

### ② 읽기 모드에서 붙여넣기가 조용히 버려지던 것

**모드를 눈치채게 하는 대신 모드가 비키게 했다.** 읽는 칸에 글자를 치거나 Ctrl+V 하면
고치기로 넘어가고 **그 입력이 살아난다.** 단축키(Ctrl+F 등)는 그대로 흘려보낸다.

### ③ 새 글·오늘 일지가 읽기 모드로 열리던 것

Ctrl+N · Ctrl+D 둘 다 **바로 쓸 수 있게** 열린다. 「고치기」를 한 번 더 안 눌러도 된다.

### ④ 저장했는지 몰랐던 것

저장하면 상태줄에 **「저장했다 — 제목」**이 1.6초 뜬다.

## 재 줄 것

```
가. sha256 · 제품 버전 0.1.58.0 · 죽음기록 · 메모리(회귀 없나)

나. ① 프론트매터
    본문 맨 위에 --- type: 시험 / status: 진행 --- 을 쓰고 저장 → 파일을 열어
    □ --- 블록이 하나인가        □ type/status 가 첫 블록 안에 있는가
    □ 읽기 모드에서 굵게 안 뜨는가  □ 검색 미리보기 첫 줄이 본문인가
    □ 옵시디언에서 열면 속성 패널에 뜨는가   ← 이게 진짜 판정이다

다. ② 붙여넣기
    읽기 모드에서 본문 자리 누르고 Ctrl+V → 고치기로 넘어가며 글이 들어오나
    글자를 그냥 쳐도 같은가 · Ctrl+F 는 글자로 안 박히나

라. ③④ Ctrl+N · Ctrl+D 가 바로 쓰이나 · Ctrl+S 에 「저장했다」가 뜨나

마. **지난번 안 잰 것들** — 이번엔 재 달라
    할 일 눌러서 켜고 끄기 · 나란히 보기 · Alt+←/→ · Ctrl+O · Ctrl+E · Ctrl+\
    검색 문법 path: / kind: / year: / "정확한 구절" / -빼기 · 서식 넣기
```

## 아직 안 고친 것 (네가 찾은 것 중)

```
② [[링크]]가 읽기 모드에서 [글](note:…) 로 날것 노출
③ 목차 안 보임
반쪽: 색상코드 #0E1116 이 본문에서 태그와 같은 붉은색으로 칠해짐
정정: 이미 저장된 제목 15개의 `--`  ← 기존 기록을 건드리는 일이라 오너 확인 대기
```

네 관찰이 좋았다 — **②는 AI 에겐 덜 아프고 사람 눈에만 지저분하다**는 것,
**사람용 렌더링과 AI 용 원문이 갈리는 자리**라는 것. 그대로 살려서 고칠 생각이다.

## 계속 부탁

- **안 잰 것을 「통과」로 적지 않는다.**
- **「고쳤다」를 새 자료로만 확인하지 않는다** — 옛 자료에 소급되는지 따로 본다.
  이번에 네가 그걸로 하나 건졌다.
