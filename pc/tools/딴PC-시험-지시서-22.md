# VC v0.1.59 — 네가 새로 찾은 셋 고침 (①②④)

네 보고 넷 중 셋을 고쳤다. ③(소급)은 오너 확인 대기다.

## ★① 제목이 정확한데 3등 — 「정할 자리」가 아니라 **잴 자리**였다

네가 「점수를 더 주면 다른 게 밀릴지 모르니 네가 정할 자리」라고 했다. 맞는 걱정이라
**가중치는 안 건드렸다.** 대신 재고 좁게 고쳤다. 오너 자료 3142장 실측:

```
[잰 것] 제목 그대로 물었을 때   1등 93% · 3등 안 99% · 여덟 밖 0
        진 것은 거의 다 **형제 제목**한테 — 「아, 그렇군요」 → 「아, 그렇군요!」가 1등
[고침]  제목이 물음과 **똑같으면** 그것부터 내놓는다 (가중치는 그대로)
[결과]  1등 93% → **100%**
[안전]  제목과 안 똑같은 물음 59개 — 차례 바뀐 것 **0개**
```

똑같을 때만 당기므로 **그 물음 하나만** 달라지고 나머지는 그대로다. 네 걱정이
현실이 되는지 숫자로 확인했다.

## ② 미리보기에 `**굵게**` 가 나오던 것 — 고침

제목에서는 벗기고 미리보기에서는 안 벗겼다. **사람에게 보일 때만 접고 원문은 파일에
그대로** 둔다 — 네가 말한 「사람용 렌더링과 AI 용 원문이 갈리는 자리」 그대로다.

## ④ 「밖에서도 고쳤길래」 헛경고 — 고침. **원인은 내 쪽이었다**

★ **네 관측은 맞았고 짐작은 틀렸다.** 이름 바꾸기가 아니라 **v0.1.58 의 프론트매터
고침이 원인**이었다. 저장할 때 본문 맨 앞 `---` 블록을 앞머리로 끌어올리니
**디스크의 본문이 네가 친 글과 달라진다.** 그런데 비교값으로 「친 글」을 들고 있어서
다음 저장 때 「어? 디스크가 다르네 = 밖에서 고쳤네」가 됐다. 이제 **디스크에 실제로
내려간 글**을 들고 있다.

※ 이걸 검사로 박다가 나도 걸렸다 — 되돌리기 검사가 **엉뚱한 줄**을 집어서
「안 잡힘」이라고 거짓 보고를 했다. 정확한 줄로 다시 재니 잡혔다.
**재는 도구가 거짓말한 자리가 또 하나 늘었다.**

# 재 줄 것

```
가. sha256 · 제품 버전 0.1.59.0 · 죽음기록 · 메모리 (회귀 없나)

나. ① 제목 물음
    □ 「안 먹는 말투」를 찾으면 그 제목의 글이 **1등**인가
    □ 다른 물음들의 차례가 지난 판과 달라졌나  ← 달라졌으면 그게 보고할 값이다
    □ 네가 늘 쓰던 물음 몇 개로 견줘 봐 달라

다. ② 미리보기
    □ 검색 결과 미리보기에 `**` 나 백틱이 남아 있나

라. ④ 헛경고
    □ 새 글 만들어 본문 맨 위에 --- type: 시험 --- 쓰고 **두 번 이상 저장**
    □ 「밖에서도 고쳤길래」가 뜨나  ← 안 떠야 한다

마. 지난번 못 잰 것
    Alt+←/→ · 서식 넣기 — 「…」 메뉴를 못 열었다고 했다. 카드가 열린 상태에서
    다시 해 보고, 그래도 못 열면 **그것 자체가 보고할 문제**다(사람도 못 찾는다).

바. **"정확한 구절" 이 순서에 영향을 안 준다** (네가 찾은 것, 아직 안 고쳤다)
    이번 판에서 ① 고침으로 가려질 수 있다. 제목과 안 똑같은 구절로 다시 재 달라.
```
