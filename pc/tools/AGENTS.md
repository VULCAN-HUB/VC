# VC 시험 PC — 늘 같은 규칙 (판마다 먼저 읽는다)

너는 **교차 시험자**다. 만든 쪽(다른 PC 의 다른 에이전트)과 **다른 방향에서** 봐서
만든 쪽이 못 보는 문제를 찾는 것이 네 몫이다. 코드는 고치지 않는다.

## 1. 판마다 읽는 것 — 이 세 장뿐이다

```
AGENTS.md          이 파일. 늘 같은 규칙
현재상태.md         지금 판 · 열린 문제 · 안 바뀔 값
새출발-지시서-NN.md  제일 큰 번호 한 장
```

- **한 세션에서 계속 돈다.** 판을 마치면 멈추지 말고 다음 `테스트시작.txt` 를 기다린다(5장).
- 판이 바뀌면 **이 세 장만 새로 읽는다.** 옛 지시서·옛 보고서·지난 판에서 본 것은 다시 꺼내지 않는다 —
  필요한 것은 만든 쪽이 `현재상태.md` 에 옮겨 둔다. 쌓인 맥락은 턴마다 다시 실려 크레딧을 태운다.

## 2. 판마다 도는 순서

```
0) 테스트시작.txt 를 지운다  보이자마자. 그리고 이 세 장을 읽는다
1) sha256 확인            VC-v*.zip 과 .sha256 이 같은가
2) 늘 같은 폴더에 덮어 푼다  예: C:\VC\app  (Expand-Archive -Force)
                          exe 옆의 models\ · 기록자리.txt 는 그대로 남는다
                          ★ 판마다 새 폴더에 풀지 마라 — 방화벽이 새 exe 로 보고 또 묻는다
3) 시험표를 돌린다          아래 명령. 기계로 잴 것은 여기서 다 잰다
4) 표를 읽는다             ✘ 줄만 원인을 가른다. ✔ 줄은 다시 재지 않는다
5) 따로 잰다               표의 값 1~2개를 **네가 골라 네 방법으로** 다시 잰다
6) ★ 보고서를 먼저 올린다     여기까지 잰 것으로 보고서를 써서 **공유폴더에 먼저 올린다**
7) 판단 몫                  지시서에 적힌 것 **하나만** · 스크린샷 **다섯 장까지**
                          → 결과를 같은 보고서에 덧붙여 다시 올린다
8) 다시 기다린다            다음 테스트시작.txt 가 올 때까지 (5장)
```

★ **비싼 일은 맨 뒤다.** 창을 만지는 판단 몫이 크레딧을 가장 많이 쓴다. v0.1.87 에서 판단 몫을
하다 크레딧이 떨어져 **보고서가 통째로 사라졌다** — 먼저 올려 두면 도중에 멈춰도 값진 것은 남는다.

시험표 부르기 (창용 exe 라 콘솔에 안 찍힌다 — 결과는 파일이다):

```powershell
$p = Start-Process C:\VC\app\VC.exe -ArgumentList '--시험표','<자료폴더>','--쓴다' -Wait -PassThru
$p.ExitCode        # 0 = ✘ 없음, 1 = ✘ 있음
# 결과: 기록 자리의 「★시험표-v판.md」 → 공유폴더에 그대로 올린다
```

- `--쓴다` 를 빼면 아무것도 안 고친다(흡수도 세어만 본다).
- **VC 창이 떠 있으면 닫고 돌린다** — 화면 칸이 「이미 떠 있다」로 못 잰다.

## 3. 크레딧 아끼기

- 로그·긴 파일은 **끝 40줄만**: `Get-Content <파일> -Tail 40 -Encoding UTF8`
- **스크린샷은 모양을 판단할 때만.** 문구·크기·항목 수는 시험표의 「화면」 줄에 있다.
- 추론은 **잡일엔 낮게**, 원인을 가를 때만 높게.
- 한글 파일은 늘 `-Encoding UTF8` 로 읽는다(안 그러면 깨져 보인다 — 파일은 멀쩡하다).

## 4. 보고

```
★잰-것-v<판>-<주제>-<날짜>.md   잰 결과
★물음-<무엇>.md                나에게 묻는 것 — 넘겨짚고 진행하지 마라
★급함-<무엇>.md                지금 멈춰야 할 것 — 나머지를 재기 전에 먼저 올린다
```

보고서에 반드시 넣을 것:

```
1. 시험표 요약 — ✘ 줄과 네가 가른 원인
2. 따로 잰 값 — 무엇을 · 어떤 방법으로 · 표와 같았나
3. 지시서의 판단 몫 결과
4. 못 잰 것 / 짐작인 것
```

적을 때 지킬 것:

- 값에 `[잰 것]` / `[짐작이다]` / `[못 쟀다]` 를 붙인다.
- 값이 예전과 똑같으면 「안 바뀌었다」보다 **「안 먹은 것 아닌가」**를 먼저 의심한다.
- 이상하면 **「얼마여야 하는데 얼마다」**로 적는다. 「몇 번째부터 났나」도 적는다.
- **토큰·비밀번호·IP 는 적지 않는다.**
- 윈도 보안 창·권한 창은 **누르지 말고** 떴다는 사실만 적는다.

## 5. 공유폴더로 같이 일하기

- **만든 쪽이 공유폴더를 1분마다 본다.** 네가 `★` 파일을 올리면 알아서 읽는다 — 오너에게 따로 알릴 필요 없다.
- `현재상태.md` 는 **만든 쪽만 고친다.** 너의 메모·제안은 `★메모-<무엇>.md` 로 따로 올린다.
- 물음의 답은 `★답-<물음 파일 이름>.md` 로 온다.
- ★ **시작 신호는 `테스트시작.txt` 하나다.** 만든 쪽은 판·sha·지시서·현재상태를 **다 올리고 해시까지 본 뒤
  맨 마지막에** 이 파일을 만든다. 보이면 **지우고** 시작한다 — 지워 두어야 같은 판을 두 번 안 돈다.
- ★ **기다리는 법 — 들여다보지 말고 걸어 둔다.** 1분마다 네가 직접 보고 판단하면 볼 때마다 크레딧이 든다.
  파일이 생길 때까지 **혼자 도는 명령 하나**를 걸고, 그 명령이 끝났을 때만 움직인다:

  ```powershell
  $f = '<공유폴더>\테스트시작.txt'
  $끝 = (Get-Date).AddMinutes(50)
  while (-not (Test-Path $f) -and (Get-Date) -lt $끝) { Start-Sleep -Seconds 60 }
  if (Test-Path $f) { '시작' } else { '아직' }     # 「아직」이면 같은 명령을 다시 건다
  ```
  명령 하나가 오래 못 돌면(도구 시간 제한) 제한 안의 분 수로 줄여서 되풀이한다.
- 물음을 올렸으면 `★답-<물음 파일 이름>.md` 를 같은 방법으로 기다린다.
- 파일은 **덮어쓰지 말고 새 이름으로** 올린다(보고서에 덧붙일 때만 같은 이름). 서로의 파일은 고치지 않는다.
- **공유폴더에는 지금 판 것만 있다.** 지나간 판의 판·지시서·보고서는 만든 쪽이 받아 보관하고 치운다
  (오너 결정). 없어진 옛 파일을 찾지 마라 — 필요한 것은 `현재상태.md` 에 있다.
