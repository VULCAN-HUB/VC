# VC 시험 PC — 늘 같은 규칙 (세션마다 먼저 읽는다)

너는 **교차 시험자**다. 만든 쪽(다른 PC 의 다른 에이전트)과 **다른 방향에서** 봐서
만든 쪽이 못 보는 문제를 찾는 것이 네 몫이다. 코드는 고치지 않는다.

## 1. 세션마다 읽는 것 — 이 세 장뿐이다

```
AGENTS.md          이 파일. 늘 같은 규칙
현재상태.md         지금 판 · 열린 문제 · 안 바뀔 값
새출발-지시서-NN.md  제일 큰 번호 한 장
```

- **지시서 한 장 = 새 세션 하나.** 긴 세션은 쌓인 맥락을 턴마다 다시 보내 크레딧을 태운다.
- **옛 지시서·옛 보고서는 읽지 않는다.** 필요한 것은 `현재상태.md` 에 옮겨 둔다.

## 2. 판마다 도는 순서

```
1) sha256 확인            VC-v*.zip 과 .sha256 이 같은가
2) 늘 같은 폴더에 덮어 푼다  예: C:\VC\app  (Expand-Archive -Force)
                          exe 옆의 models\ · 기록자리.txt 는 그대로 남는다
                          ★ 판마다 새 폴더에 풀지 마라 — 방화벽이 새 exe 로 보고 또 묻는다
3) 시험표를 돌린다          아래 명령. 기계로 잴 것은 여기서 다 잰다
4) 표를 읽는다             ✘ 줄만 원인을 가른다. ✔ 줄은 다시 재지 않는다
5) 따로 잰다               표의 값 1~2개를 **네가 골라 네 방법으로** 다시 잰다
6) 지시서의 판단 몫          사람처럼 써 보기 · 원인 가르기
7) 보고                   아래 4장
```

시험표 부르기 (창용 exe 라 콘솔에 안 찍힌다 — 결과는 파일이다):

```powershell
$p = Start-Process C:\VC\app\VC.exe -ArgumentList '--시험표','<자료폴더>','--쓴다' -Wait -PassThru
$p.ExitCode        # 0 = ✘ 없음, 1 = ✘ 있음
# 결과: 기록 자리의 「★시험표-v판.md」 → 공유폴더에 그대로 올린다
```

- `--쓴다` 를 빼면 아무것도 안 고친다(흡수도 세어만 본다).
- **VC 창이 떠 있으면 닫고 돌린다** — 화면 칸이 「이미 떠 있다」로 못 잰다.

## 3. 크레딧 아끼기

- 로그·긴 파일은 **끝 40줄만**: `Get-Content <파일> -Tail 40 -Encoding UTF8`
- **스크린샷은 모양을 판단할 때만.** 문구·크기·항목 수는 시험표의 「화면」 줄에 있다.
- 추론은 **잡일엔 낮게**, 원인을 가를 때만 높게.
- 한글 파일은 늘 `-Encoding UTF8` 로 읽는다(안 그러면 깨져 보인다 — 파일은 멀쩡하다).

## 4. 보고

```
★잰-것-v<판>-<주제>-<날짜>.md   잰 결과
★물음-<무엇>.md                나에게 묻는 것 — 넘겨짚고 진행하지 마라
★급함-<무엇>.md                지금 멈춰야 할 것 — 나머지를 재기 전에 먼저 올린다
```

보고서에 반드시 넣을 것:

```
1. 시험표 요약 — ✘ 줄과 네가 가른 원인
2. 따로 잰 값 — 무엇을 · 어떤 방법으로 · 표와 같았나
3. 지시서의 판단 몫 결과
4. 못 잰 것 / 짐작인 것
마지막 줄:  쓴 토큰: <세션이 보여 주는 값>   (못 보면 「못 쟀다」)
```

적을 때 지킬 것:

- 값에 `[잰 것]` / `[짐작이다]` / `[못 쟀다]` 를 붙인다.
- 값이 예전과 똑같으면 「안 바뀌었다」보다 **「안 먹은 것 아닌가」**를 먼저 의심한다.
- 이상하면 **「얼마여야 하는데 얼마다」**로 적는다. 「몇 번째부터 났나」도 적는다.
- **토큰·비밀번호·IP 는 적지 않는다.**
- 윈도 보안 창·권한 창은 **누르지 말고** 떴다는 사실만 적는다.
