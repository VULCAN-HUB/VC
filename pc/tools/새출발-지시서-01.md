# VC 시험 — 처음부터. **이 한 장만 읽으면 된다**

앞의 자료는 아무것도 없다고 보고 적는다. 순서대로 따라오면 된다.

---

# 0. 이게 뭐고, 네가 뭘 하면 되나

## VC 가 무엇인가

오너의 **개인 지식창고 + AI 작업 도구**다. 옵시디언과 같은 자리를 노린다.

```
글은 전부 .md 파일이고 그게 원본이다     색인(db)은 언제든 다시 만드는 사본일 뿐
바깥 프로그램(메모장·옵시디언)으로 고쳐도 된다
인터넷 없이 이 PC 안에서 다 돈다
```

★ 다만 사람용 노트앱이 목표가 아니다. **AI 가 읽고 쓰는 바깥 기억**이다 —
AI 가 모든 걸 기억할 수 없으니 창고에 꺼내 두고 필요할 때 꺼내 쓴다는 얼개다.
그래서 「사람이 훑기 좋은가」만이 아니라 **「AI 가 꺼내 쓰기 좋은가」**도 잣대다.

## 네가 하는 일

**직접 써 보고, 안 되는 것과 불편한 것을 값으로 적어 주는 것.**
버그만이 아니다 — **불편·불안(지워질까 봐 무섭다 등)·헷갈림도 정식 보고 대상**이다.

## 주고받는 자리 — 공유폴더 하나뿐이다

```
내가 보내는 것   VC-v*.zip · .sha256 · 새출발-지시서-*.md · ★판-올렸다-*.md
네가 보내는 것   ★잰-것-*.md      잰 결과
                ★물음-*.md       나에게 묻는 것
                ★급함-*.md       지금 멈춰야 할 것
```

★ **막히거나 궁금하면 `★물음-<무엇>.md` 로 물어라.** 내가 보고 지시서로 답한다.
**혼자 넘겨짚고 진행하지 마라** — 짐작으로 적힌 값은 나중에 다 다시 재야 한다.

★ **뭔가 크게 잘못됐으면 `★급함-*.md` 를 먼저 올려라.** 나머지를 다 재고 나서
알릴 필요 없다. 안 뜨는 판으로 나머지를 재 봐야 무엇이 그 판 탓인지 못 가른다.

## 적을 때 지킬 것 다섯

```
1. 잰 값을 적어라 — 「잘 된다」보다 「8장 · 1,927자 · 0.6초」가 값지다
2. 못 잰 것은 못 잰 것으로 갈라 적어라. 짐작이면 [짐작이다] 라고 붙여라
3. 값이 예전과 똑같으면 「안 바뀌었다」가 아니라 「안 먹은 것 아닌가」를 먼저 의심해라
4. 토큰·비밀번호·IP 주소는 보고서에 적지 마라. 「됐다/안 됐다」면 충분하다
5. 눈으로 못 세겠으면 세어 주는 것을 찾아라 (--doctor · --이음선 · --찾기점수)
```

# 1. 깔기 · 첫 확인

설치 과정이 없다. **zip 을 풀고 VC.exe 를 켜면 끝이다.**

```
VC-v0.1.81.zip 을 아무 폴더에나 푼다 (예: C:\VC)
```

```
□ sha256 이 VC-v0.1.81.zip.sha256 의 값과 같나
□ VC.exe 를 오른쪽 눌러 속성 → 자세히 → 제품 버전이 0.1.81.0 인가
□ 켜서 창 제목이 「VC」인가
□ 작업 관리자에서 메모리가 약 490MB 인가   ★ 49MB 면 그건 창이 아니라 오류 상자다
□ 창을 최소 크기로 줄여 봐라 — 몇 x 몇 인가. 네 화면에 들어가나
□ 창이 안 뜨면 → `VC.exe --doctor` (창 없이도 상태를 다 적어 준다)
```

## 명령줄로 쓸 수 있는 것 (전부다)

```
VC.exe                      그냥 켠다
VC.exe --도움말              쓸 수 있는 것을 적어 준다
VC.exe --doctor             지금 상태를 적어 준다 (자리·항목 수·연결·판 적합률 …)
VC.exe --report             진단 묶음(zip)을 만든다
VC.exe --흡수 <폴더>          폴더의 글을 창고로 들인다 (--쓴다 없으면 세어만 본다)
VC.exe --사본치우기            같은 내용이 겹친 것을 찾는다 (--쓴다 없으면 세어만)
VC.exe --판올리기             옛 형식의 글을 새 형식으로 올린다 (--쓴다 없으면 세어만)
VC.exe --이음선              글끼리 이어진 짝을 적어 준다
VC.exe --색인다시             색인만 다시 만든다 (글은 안 건드린다)
VC.exe --찾기점수 [물음파일]    찾기가 얼마나 맞히는지 잰다
VC.exe --no-server           원격(폰) 서버를 안 켜고 켠다
VC.exe --check              자체 점검
```

★★ **`--쓴다` 를 안 붙이면 아무것도 안 고친다.** 마음껏 세어 봐도 된다.
글을 치울 때도 지우지 않고 `.이력/` 폴더로 옮긴다 — 되돌릴 수 있다.

# 2. ★ 기준값 잡기 — 이번 판의 본론

창고가 비어 있다. **앞으로 모든 비교의 바탕이 될 숫자**를 지금 만든다.

## 가. 빈 창고에서
```
VC.exe --doctor
□ 「기록 자리」와 「색인」이 어디인가        ← 경로를 적어 줘. 뒤에 계속 쓴다
□ 항목 수 · 연결 수 · 판 적합률
□ 「듣는 자리」 줄이 있나
```
창에서도 봐라:
```
□ 위 띠에 「★ 원격 열림 :8765」가 있나
□ 마우스를 올리면 0.0.0.0 · 401 · --no-server 세 가지가 다 나오나
□ VC.exe --no-server 로 켜면 그 줄이 아예 없나   ← 있으면 거짓말이다
```
※ 이건 **같은 공유기의 다른 기기에서 이 PC 에 닿을 수 있다**는 뜻이다. 토큰이 없으면
  막히지만(401), 열려 있다는 사실 자체를 쓰는 사람이 알아야 해서 창에 적는다.

## 나. 네 자료를 부어 본다
버려도 되는 사본 폴더를 하나 골라라 (문서·메모 아무거나. 원본 말고 사본으로).

```
VC.exe --흡수 <폴더>              ← 세어만 본다
□ 본 것 · 들인 것 · 겹친 것 · 버린 것
□ **본 것 = 들인 것 + 겹친 것 + 버린 것** 인가   ← 안 맞으면 그게 결함이다

VC.exe --흡수 <폴더> --쓴다
□ 몇 장 들어왔나 · 몇 초 걸렸나

VC.exe --흡수 <폴더>              ← **같은 폴더를 한 번 더** 세어 본다
□ 겹친 것이 전부이고 **들인 것이 0** 인가   ← 두 번 부어도 안 쌓여야 한다
```

# 4. AI 가 꺼내 쓰는 길 (해 볼 수 있으면)

서버가 떠 있어야 한다(그냥 켜면 뜬다). 토큰은 `--doctor` 에 있다. **값은 적지 마라.**

```
1단  GET http://127.0.0.1:8765/eb/v1/memory/search?q=<찾을말>
     Authorization: Bearer <토큰>
□ 결과에 body 가 **없나**  (title · summary · headings · chars 만 와야 한다)
□ 통째로 몇 자인가          ← 네 창고에서 이 값이 값지다

2단  GET .../eb/v1/memory/note?title=<제목>&heading=<소제목>
□ 그 소제목 아래 **한 토막만** 오나
□ 없는 소제목을 주면 404 + 있는 소제목 목록이 오나   ← 글 통째가 오면 잘못이다
□ heading 없이 부르면 글 한 편이 오나
□ ...?full=1&q=... 이면 body 가 오나
```
※ 까닭: 예전엔 찾을 때마다 걸린 글의 **본문을 통째로** 줘서 한 번에 몇만 자가 나갔다.
  목록 먼저 주고 **고른 것만 펼치는** 두 단으로 갈랐다.
