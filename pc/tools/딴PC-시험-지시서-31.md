# VC v0.1.72 — 사본 치우기

**이번 판에 든 것은 하나다.** 오너가 ①(진짜 동일 사본) 청소를 하라고 정했다.

## 무엇을 했나

만든 쪽 기록에서 **본문이 글자까지 똑같은 항목**을 하나만 남기고 치웠다.

```
[잰 것] 3183장 중 본문이 똑같은 뭉치 388개 · 치울 것 388장 (12.2%)
[한 것] 3183 → 2795장
[그물]  near-중복 40% → **9%**  ·  진짜 다른 것 60% → **91%**
```

원인이 뚜렷했다 — **같은 글이 두 나무에서 흡수됐다.** 볼트에 한 벌, `프로젝트`
폴더 안 **옛 VC 기록 사본**에 한 벌. 그래서 하나에만 출처가 덧붙어 있었다:

```
0단계 실제 결과 (2026-08-07) (eb)     ← 치웠다 (출처가 덧붙은 쪽)
0단계 실제 결과 (2026-08-07)          ← 남겼다
```

## 안전장치 넷

```
미리보기가 기본        --쓴다 를 붙여야 움직인다 (흡수와 같은 결)
지우지 않고 치운다      .이력/ 으로 옮긴다 — delete() 는 파일을 그냥 없앤다
사람 손질 있으면 안 함   다시 붓기와 같은 잣대
가리키는 것 있으면 둠    치우면 그 이음이 허공을 가리킨다 (이번엔 걸린 게 0장)
멱등                  다시 돌리면 0장
```

# 재 줄 것

## 가. 받자마자

```
sha256 · 제품 버전 0.1.72.0 · 창 제목 「VC」 · 메모리 · 죽음기록
```

## 나. ★ 사본 치우기 — **네 기록에서**

네 기록에도 사본이 있는지 모른다. **먼저 세어만 보고**, 숫자를 보고 정해라.

```
VC.exe --사본치우기              ← 세어만 본다. 아무것도 안 움직인다
```

```
□ 몇 뭉치 · 몇 장으로 나오나
□ 「치울 것」과 「남길 것」 짝이 그럴듯한가 (긴 쪽이 치워지고 짧은 쪽이 남나)
□ 「가리키는 것이 있어 그냥 둔 것」이 몇 장인가
```

★ **여기서 멈춰라.** `--쓴다` 는 **숫자를 보고 정한 뒤에** 하면 된다.
치우면 `.이력/` 에 남아 되살릴 수 있지만, **네 기록은 옛 판이 섞인 시험대**라
그 성질이 바뀌는지부터 봐야 한다.

```
□ (치울 생각이면) 치우기 전에 판 적합률·항목 수를 적어 둔다
□ 치운 뒤 그 둘이 **치운 장수만큼만** 달라지나   ← 「이건 안 바뀌어야 한다」 칸
```

## 다. 지난 판 것 — 아직 못 잰 넷

지시서 30 「나」가 그대로 남아 있다. **v0.1.72 에서 새로 재라**(판이 다르면 못 견준다).

```
VC.exe --찾기점수                              1등 ? · 3등 안 ? · 밖 ?
VC.exe --찾기점수 --제목벡터빼고                  1등 ? · 3등 안 ? · 밖 ?
VC.exe --찾기점수 --빼고 점검보고                 1등 ? · 3등 안 ? · 밖 ?
VC.exe --찾기점수 --빼고 점검보고 --제목벡터빼고     1등 ? · 3등 안 ? · 밖 ?
```

★ **스위치가 먹었는지 머리글로 먼저 확인해라** — 네가 세운 규칙 그대로.
`--제목벡터빼고` 는 이제 아는 스위치라 모르는 것으로 안 떨어진다. 확인용으로
`VC.exe --없는스위치` 를 한 번 해 보면 **「모르는 것이다」 찍고 창 없이 끝나야** 한다.

## 라. 이건 안 바뀌어야 한다

```
목차 (창 922 접힘 · 1500 위 줄) · [[링크]] 눌러 가기 · 이어보기 칸 · 앞머리 한 겹
```

## 명령에 곁딸린 것 (다 적는다)

```
--사본치우기 [--쓴다] [--그래도쓴다]
    (없이)        세어만 본다
    --쓴다         .이력/ 으로 치운다
    --그래도쓴다     사람이 손댄 기록이 있어도 한다 (평소엔 막힌다)

--찾기점수 [물음파일] [--빼고 <출처조각>] [--제목벡터빼고]
--흡수 <폴더> [--쓴다] [--그래도쓴다]
--doctor · --report · --색인다시 · --이음선 · --도움말 · --check
```

## 내가 이번에 두 번 속았다

검사를 만들다 **재는 도구가 두 번 거짓말**을 했다.

```
1. 소스를 잘라 봤더니 **검사 코드 자체에 같은 글자**가 있어 자르는 자리가 어긋났다
2. 고쳤더니 이번엔 **검사문에 적은 글자가 스스로를 만족**시켰다 — 고침을 빼도 통과
```

**세는 방식**으로 바꾸고서야 잡힌다(검사 자신이 한 번 쓰니 **둘 이상**이어야 한다).
→ **「들어 있나」로 소스를 보면 검사가 제 꼬리를 문다.**
네 「값이 똑같으면 안 먹은 것 아닌가를 먼저 묻는다」와 같은 자리다.
