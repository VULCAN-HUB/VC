```
VC-v0.1.86.zip
SHA-256  9E5CA31A2FAC38E912390D4825E350DE6964A440F1E4F33D5568B53FA9566C16
```

오너가 정했다: **「버린 것은 휴지통에 모아 두고, 휴지통에서 찾으라고 하기 전까지 안 찾는다.
안 비운다.」** 네가 잰 「재심사 5조각」이 이 결정을 끌어냈다.

# 1. 들어간 것

```
문지기가 버린 조각  →  기록 자리의 「휴지통」 폴더에 .md 로 남는다
                    앞머리에 출처 · 줄 · 버린날 · 까닭 · 지문이 함께 적힌다
찾기·색인·그물      휴지통을 **아예 안 본다** (글 폴더 밖이다)
다시 부을 때        휴지통에 있는 것은 **문지기에게 다시 안 물어본다**
되살리기           그 파일을 글 폴더로 옮기면 그대로 항목이 된다 (파일이 원본이다)
비우기             **안 비운다.** 지우는 명령을 아예 안 만들었다
```

## 잰 것 (네가 준 자료 그대로)

```
1차 --흡수 --쓴다   15초 · 4개 씀 · **버린 것 4개를 휴지통에 뒀다**
2차 --흡수         **후보 0 · 겹친 것 9** — 문지기를 한 번도 안 불렀다 (즉시 끝)
                  (v0.1.84 에서 네가 잰 「후보 5가 다시 심사」가 사라졌다)
찾기              「과정」·「안녕」 → 0건.  휴지통에 있는 것은 안 걸린다 ✓
```

# 2. 새 명령

```
VC.exe --휴지통              담긴 것 수 · 앞 40개 · 각 조각의 첫 줄
VC.exe --휴지통 <찾을말>      그 말이 든 것만
   (결과는 vc-휴지통.txt 에도 적는다)
```

# 3. 재 줄 것

## 가. ★ 휴지통 — 이번 판 본론
```
□ 네 자료로 --흡수 --쓴다 → 「버린 것 N개는 휴지통에 뒀다」가 뜨나
□ VC.exe --휴지통 → N개가 보이나 · 앞머리에 출처/줄/버린날이 있나
□ 같은 폴더를 **다시** --흡수 → **후보 0 · 겹친 것 전부** 인가
   ★ 여기서 시간이 확 줄어야 한다 (전에 35초 걸리던 자리)
□ 창에서 휴지통에 있는 말로 찾기 → **안 나와야 한다**
□ 휴지통 파일 하나를 글 폴더로 옮기면 항목이 되나 (되살리기)
```

## 나. 지난 판 것 — 아직 못 잰 것
```
□ 창이 서버와 이야기하나 (지시서 07 「가」) — 「엔진 llama …」로 바뀌나 · 모델 칸이 차나
□ 긴 글 목차로 이동 · 창 최소 크기 · [[링크]] 눌러 가기 · 뒤로 · 밖에서 고친 것
□ 30분 그냥 써 보기
```

## 다. 안 바뀔 것
```
장문 다섯 값(356 · 849 · 404 · 3226 · 3457) · --check · --사본치우기/--판올리기 stdout
씨앗 흡수 통과 · 기록자리.txt · 벡터 다 찬 뒤의 맞짝 수
```

★ 네 창고에는 **v0.1.84 까지 버려진 조각이 휴지통에 없다** — 그건 이 판이 생기기 전에
버려진 것이라 자리가 없었다. 다시 부으면 **한 번은 물어보고, 그 뒤로는 휴지통에 남는다.**
그러니 「두 번째 흡수부터」가 이 기능을 재는 자리다.
