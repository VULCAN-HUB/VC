# VC v0.1.55 — 판 번호가 물건 안에 들어갔다

먼저 네가 쓴 24-1 을 읽었다. **80MB 를 다시 잰 것이 옳았다.**
그리고 네가 굳힌 규칙(「메모리는 뜬 뒤 30초는 지나서 잰다」)을 **물건 쪽에서
안 외워도 되게** 바꿔 놨다. 이번 판의 절반이 그 이야기다.

---

## 1) 메모리가 스스로 말한다

진단 묶음(`--report`)에 메모리와 **켠 지**가 같이 찍힌다.

```
메모리: 494MB (최고 511MB · 켠 지 3분 12초)
메모리: 22MB (최고 24MB · 켠 지 0분 8초)  ← **아직 다 안 올라왔다. 30초 뒤에 다시 봐라**
```

30초가 안 지났으면 값 옆에 그렇게 적힌다. 이제 **밖에서 따로 잴 일이 없다.**
「[자는 중]」이나 「간격 바람/실제」와 같은 결이다 — 값이 스스로 말하게 한다.

만들다 하나 걸렸다. 처음엔 **0MB 가 찍혔다.** 인자 타입을 안 박아서 프로세스
핸들이 잘렸고 함수가 실패했는데, 돌려주는 값을 안 보니 0 이 그냥 찍혔다.
**0 은 「안 쓴다」가 아니라 「못 쟀다」인데 구별이 안 됐다** — 네가 앞서 짚은
「못 알아들은 것 0%」와 같은 병이다. 검사에 박아 뒀다.

## 2) 판 번호가 exe 와 진단에 들어갔다

그동안 exe 속성에는 **`0.1.0.0`** 이 박혀 있었다. 진짜 판은 파일 이름과
알림 글에만 있었다. **네가 지금 무엇을 돌리고 있는지 물건만 보고는 못 갈랐다.**

이제 두 자리에서 보인다:

```
VC.exe 오른쪽 클릭 → 속성 → 자세히 → 제품 버전   0.1.55.0
진단 묶음 맨 위                                   판: v0.1.55
```

## 3) 기록 자리를 쪽지로 옮길 수 있다 — **너는 안 건드려도 된다**

딸린 것 옆에 `기록자리.txt` 를 두면 기록이 그 자리로 간다. **네 PC 에는 그
파일을 안 넣었다.** 없으면 예전과 똑같이 `문서\VC` 로 간다. 확인만 해 주면 된다.

## 4) 흡수 쪽 (네가 안 돌리면 안 보인다)

만든 쪽 PC 에서 실제로 1642장을 부어 보고 둘을 고쳤다.

- 문지기 문틀에 「남의 설명서는 버린다」가 있었는데 **뺐다.** 오너가 짚었다 —
  본인이 안 쓴 자료도 필요하다(AI 가 자료를 어떻게 다루는지 같은 것). 300 조각에
  두 문틀을 나란히 태워 재고 바꿨다: 145/300 → 178/300, 살아난 35개가
  「QR코드 방식으로 확정합니다」(결정) 같은 **오너 본인의 결정**이었다.
- 제목에서 꾸밈 글자를 벗겼다. 부어 놓은 것의 **11.1%(182장)** 가
  `**Second Brain**가…` → `-Second Brain-가…` 로 뭉개져 있었다.
  그리고 제목이 「네, 좋습니다」인 항목 스무 장을 다음 문장으로 넘겼다.

# 재 줄 것

## 가. 받자마자 (5분)

```
1. sha256 이 알림 글과 같은지
2. 띄운다 — 뜨나
3. VC.exe 속성 → 제품 버전이 0.1.55.0 인가
4. 죽음기록 크기 (늘었으면 무언가 죽은 것이다)
```

## 나. 메모리 — **이번 판의 본론** (2분)

띄우고 **바로** 진단을 뽑고, 30초 뒤에 한 번 더 뽑아라.

```
뜬 직후:  ____MB · 켠 지 ____   「다시 봐라」가 붙었나? (예/아니오)
30초 뒤:  ____MB · 켠 지 ____   「다시 봐라」가 사라졌나? (예/아니오)
```

★ **0MB 가 찍히면 그것만으로 보고할 값이 있다.** 네 PC 에서 그 함수가 다르게
도는 것이고, 그건 여기서는 못 보는 것이다.

## 다. 마지막으로 잰 판이 v0.1.52 라 (네 24-2)

세 판을 건너뛰었으니 이번에 한 번 훑어 달라. **안 재도 되는 것은 없다.**

```
가만히 뒀을 때 CPU        ____%    (v0.1.52 때 3% 대)
창을 작게 밀었을 때 크기   ____x____ (바닥 430)
상태줄이 안 잘리나
⚠ 가 뜨면 무엇인지 말하나
```

## 라. 흡수를 돌려 볼 생각이면 (안 돌려도 된다)

```
--흡수 <폴더>          세어만 본다 (아무것도 안 쓴다)
--흡수 <폴더> --쓴다    쓴다
```

제목에 `--` 가 남아 있으면 그건 아직 안 고쳐진 것이다. 알려 달라.

# 알아 둘 것

**판마다 zip 을 쌓아 둘 필요 없다.** 오너가 정했다 — 개발 쪽 노트북에 소스
이력이 생겼고, 되돌릴 일이 있으면 거기서 그 판을 다시 구워 보낸다.
공유 폴더에는 지금 판 하나만 있으면 된다. 옛 zip 은 지워도 된다.

**안 잰 것을 「통과」로 적지 않는다** — 네 규칙 그대로다. 이번에도 그렇게 적어 달라.
