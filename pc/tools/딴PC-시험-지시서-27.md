# VC v0.1.64 — 네가 찾은 둘 + 소급 바탕을 깔았다

이번 판은 둘로 갈린다. **네가 찾은 것 둘**과, **오너가 정한 소급 작업**이다.

## 네가 찾은 것

### ★ ② 목차 — 접기 문제가 아니었다

네가 「808px 인데도 위 줄에 없고 「…」 에도 없다」고 한 것이 결정적이었다.
560 보다 넓은데 없다는 것은 **접기가 원인이 아니라는 뜻**이었다.

재현하니 이랬다:

```
목차를 채우는 자리가 **항목을 열 때만** 불린다.
  → 새 글은 **빈 채로** 열린다(소제목 0개) → 목차 숨김
  → 소제목을 쳐 넣고 저장해도 **다시 안 채운다** → 영영 안 뜬다
```

**네가 글을 직접 쳐서 만들었기 때문에 걸렸다.** 내 검사는 파일로 미리 만들어
열었기 때문에 통과했다 — **또 내 도구가 실물과 다른 길을 밟았다.**
이제 저장할 때마다 목차를 다시 채운다.

### ③ 미리보기에서 `[[ ]]` 와 `##` 가 안 펴지던 것

네 짐작이 맞았다 — **카드 렌더링과 미리보기가 따로 놀았다.** `**` 만 벗기고
`[[ ]]`·`##` 는 안 벗겼다. 이제 셋 다 편다:

```
전:  **##** 첫째 소제목 … **[[안 먹는 말투]]** 과 **[[기록**…
후:  첫째 소제목 … 안 먹는 말투 과 기록 과 안 먹는 말투 › 첫째 다.
```

`[[제목#소제목]]` 은 미리보기에서도 「제목 › 소제목」으로 편다.

## 오너가 정한 소급 작업 (네 시험과는 다른 축)

기록을 **다시 부었다**(3183장). 그 전에 넷을 갖췄다:

```
스키마 판번호     모든 항목에 「스키마: 1」. 없으면 0판 = 아직 안 옮긴 것
흐린 선          흡수 글의 [[ ]] 를 **갈라서** 넣는다 (진한 선 0 / 흐린 선 1)
다시 붓기 막이    사람이 손댄 항목이 하나라도 있으면 **거부한다**
사이드카 지문     밖에서 온 글이 5분 규칙에 걸려 사라지던 것을 막는다
```

잰 것:

```
스키마 1판 3183장 (100%) · 0판 0장
이음 — 진한 선 0 · 흐린 선 492      (붓기 전: 통째로 0개)
그물 near-중복 40% → 25% · 진짜 다른 것 60% → 75%
```

★ **그물이 이제 실제 자료에서 연결을 갖는다.** 전엔 이음이 통째로 0이었다 —
「유기적으로 연결하는 지식창고」가 목표인데 연결이 없었다.

# 재 줄 것

```
가. sha256 · 제품 버전 0.1.64.0 · 죽음기록 · 메모리

나. ★ ② 목차 — **네가 하던 그대로 직접 쳐서**
    □ Ctrl+N 으로 새 글 → `## 첫째` `## 둘째` `## 셋째` 를 **쳐 넣고** Ctrl+S
    □ 목차가 위 줄에 뜨나          ← 이번 판 본론
    □ 골라서 그 자리로 가나
    □ 카드를 좁히면 「…」 로 옮겨가나 · 넓히면 위 줄로 돌아오나
    □ **이미 있던 글**(파일로 만든 것)을 열어도 목차가 뜨나

다. ③ 미리보기
    □ `[[ ]]` 가 괄호째 안 보이나 · `##` 가 안 보이나
    □ `[[제목#소제목]]` 이 「제목 › 소제목」으로 보이나
    □ `**` 는 그대로 안 남나 (지난 판 통과분)

라. 그물 — 새로 생긴 자리
    □ 그래프에 **선이 보이나** (전엔 이음이 0이라 선이 없었다)
    □ 선이 이어 놓은 둘이 실제로 관련 있어 보이나
    □ 항목을 열었을 때 「이어보기」에 딴 항목이 뜨나

마. 회귀 — 지금까지 통과분
    [[링크]] 눌리는 모양 · 색상코드 안 칠해짐 · "안 먹는 말투" 1등 ·
    따옴표 한 겹 · 앞머리 한 겹 · ④ 헛경고 안 뜸 · ⚠ 안 가려짐
```

## 네가 지난번 못 잰 것 둘

```
[[링크]] 눌러서 가는지   창이 작아져 좌표를 다시 잡아야 했다 — 이번에 재 달라
첨부(그림)              넣을 그림이 없었다 — 없으면 그냥 「안 잼」으로 둬도 된다
```

## 새로 생긴 자리 하나

이름 바꾸기를 하다 말면(중간에 죽으면) **켤 때 알려 준다** — 「이름 바꾸기를 하다
말았어 — 「가」 → 「나」」. 여러 파일을 건드리는 일이라 반쯤 고쳐진 채 남을 수 있어서다.
**일부러 만들 필요는 없다.** 혹시 그 말풍선을 보게 되면 알려 달라.

## 이번에도 「같은 일이 여러 군데」

이번 세션에서 **다섯 번째**다 — 따옴표 4군데, 태그 2군데, 미리보기 2군데,
그리고 이번에 **스키마 정의가 두 벌**이었다(앞것은 죽은 코드라 그쪽을 고쳤다가 안 먹었다).
네 말대로 **「몇 군데인가」를 눈으로 세면 안 된다.**
