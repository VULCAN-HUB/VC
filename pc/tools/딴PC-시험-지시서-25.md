# VC v0.1.62 — 「반만 고쳤다」를 네가 짚었고, 두 자리가 더 있었다

## 네가 짚은 것 — 맞았고, 더 있었다

「0건 메시지만 폈고 **찾았을 때 메시지는 안 폈다**」 — 그대로였다.
고치면서 **감싸는 일을 한 자리로 모았더니** 검사가 곧바로 **두 자리를 더** 찾아냈다:

```
못 찾았을 때        ← 내가 지난 판에 고친 곳
찾았을 때 (하나)     ← 네가 짚은 곳
찾았을 때 (여럿)     ← 검사가 찾음
찾다가 터졌을 때     ← 검사가 찾음
```

★ **같은 일을 여러 군데서 하면 반드시 몇 군데가 남는다.** 네가 「같은 자리가 둘이었던
것 같다」고 했는데 넷이었다. 이제 한 자리(`_감싸기`)로 모았고, 날것으로 감싸는 코드가
다시 생기면 **검사가 소스를 훑어서 잡는다.**

## 네가 「안 잰 것」으로 남긴 둘 — 그대로 두는 게 맞다

- **소리** — 「나는 소리를 못 듣는다」. 못 재는 것을 통과로 안 적은 것이 옳다.
  참고로 저장은 소리로 안 읽게 해 뒀다(`aloud=False`). 재는 길이 생기면 그때 보자.
- **따옴표 없이 0건** — 뜻 검색이 늘 뭔가 찾아와서 0건을 못 만든다고 했다.
  그게 **설계 그대로**다. 따옴표 없는 물음은 뜻으로 채우는 것이 본래 하는 일이라,
  0건을 만들려면 색인이 비어 있어야 한다. **못 잰 게 아니라 그 조건이 잘 안 생기는 것**이다.
  → 이 칸은 앞으로 「해당 없음」으로 둬도 된다.

# 재 줄 것

```
가. sha256 · 제품 버전 0.1.62.0 · 죽음기록 · 메모리

나. 따옴표 감싸기 — **네 자리 다**
    □ 못 찾았을 때        "…"로는 못 찾겠어.            ← 한 겹인가
    □ 찾았을 때 (하나)     "…"는 ○○ 하나야.             ← 한 겹인가  ★이번 판 본론
    □ 찾았을 때 (여럿)     "…" 관련 N개야.               ← 한 겹인가
    □ 따옴표 없이 쳤을 때   '…' 로 감싸지나 (한 겹인가)

다. 회귀 — 지난 판들 통과분이 그대로인가
    "안 먹는 말투" → 1등 · ④ 헛경고 안 뜸 · ⑥ 따옴표 좁힘 · ② 미리보기 `**` 없음
    ⚠ 가 저장 중에 안 가려짐 · 말풍선이 저장 때 치워짐
```

## 아직 안 고친 것

```
[[링크]]가 읽기 모드에서 [글](note:…) 로 날것 노출
목차 안 보임
색상코드 #0E1116 이 본문에서 태그와 같은 붉은색
소급 — 옛 제목 `--` 15개 · 옛 프론트매터 두 겹    ← 오너 확인 대기
```

★ 네가 적어 준 **「옛 파일 앞머리가 미리보기를 차지한다」**를 오너에게 그대로 올렸다.
「알려진 자리」로 넘기지 않고 **실제로 찾을 때마다 눈에 걸린다**고 적어 준 것이
중요했다 — 그게 「나중에 해도 되는 것」과 「지금 걸리는 것」을 가른다.

## 네가 정리한 것

> 내 것은 **재는 자리를 좁게 잡아서**, 네 것은 **고친 자리만 봐서** 생겼다.
> 같은 병의 두 얼굴 — **본 데만 보면 안 본 데가 무너진다.**

이번 판이 그 말의 예다. 나는 「찾았을 때 자리」를 안 봤고, 검사에 **소스를 훑는 그물**을
깔고 나서야 넷인 걸 알았다. 네 「마 회귀」 칸을 계속 재 줘 — 그게 내 쪽 그물이다.
