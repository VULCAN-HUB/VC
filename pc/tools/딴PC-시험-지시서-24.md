# VC v0.1.61 — 네가 잡은 회귀 둘, 둘 다 내가 만든 것이었다

지난 판에서 네가 찾은 것 셋을 고쳤다. **둘은 내가 앞 판에서 새로 만든 회귀**다.

## ★ ① 따옴표를 치면 제목 우선이 꺼지던 것

네 관찰이 정확했다:

```
안 먹는 말투      → 1등  ✓
"안 먹는 말투"    → 3등  ✗      ← 따옴표를 붙이면 꺼진다
어색한 문장 고치기 → 따옴표 있든 없든 1등   (그 말이 딴 글에 적어서 안 드러났다)
```

★ 네 짐작(「따옴표 길에서는 빈도로만 줄을 세우고 제목 보정이 안 들어간다」)이 **맞았다.**
까닭은 더 단순했다 — 제목을 **따옴표째** 견줬다. `"안 먹는 말투"` 와 `안 먹는 말투` 는
영영 안 맞는다. 그래서 조용히 꺼졌다. 구절도 후보에 넣어 고쳤다.

**사람은 정확히 원할수록 따옴표를 치는데 하필 그때 꺼져 있었다.**

## ② 「저장했다」가 ⚠ 를 가리고, 말풍선이 안 치워지던 것

네가 둘을 한 번에 짚었다. 원인이 하나였다 — **내가 「저장했다」를 상태줄에 쓴 것.**

```
상태줄은 ⚠ 가 사는 자리     → 저장할 때마다 1.6초씩 ⚠ 가 가려졌다
말풍선은 저장이 안 건드림    → 지나간 경고가 계속 떠 있었다
```

**말풍선으로 옮기니 둘 다 풀린다.** 저장하면 지난 경고가 치워지고, ⚠ 는 안 가려진다.
소리로는 안 읽는다(저장할 때마다 말하면 시끄럽다).

## ③ 0건일 때 — 네 제안대로

네가 「지금 쪽이 낫다, 다만 따옴표를 떼면 나온다는 걸 알려 주면 더 낫겠다」고 했다.
그대로 했고, 따옴표 두 겹도 폈다:

```
전:  '"소리 읽으면"'로는 못 찾겠어.
후:  "소리 읽으면"로는 못 찾겠어. 따옴표를 떼면 비슷한 게 2개 있어.
```

# 재 줄 것

```
가. sha256 · 제품 버전 0.1.61.0 · 죽음기록 · 메모리

나. ★ ① 따옴표 + 제목 — 지난 판에 깨졌던 자리
    □ "안 먹는 말투"       → 1등인가   ← 이게 이번 판 본론
    □ 안 먹는 말투         → 1등 그대로인가
    □ "어색한 문장 고치기"  → 1등 그대로인가
    □ 그 말이 본문에 많이 든 딴 제목으로도 한 번 더 (네가 갈래를 짚은 그 조건)

다. ② 말풍선·상태줄
    □ 저장하면 말풍선이 「저장했어 — 제목」으로 바뀌나 (지난 경고가 치워지나)
    □ 저장하는 동안 ⚠ 가 상태줄에 그대로 있나  ← 안 가려져야 한다
    □ 소리가 나지 않나 (저장은 말로 안 읽는다)

라. ③ 0건 메시지
    □ 따옴표가 한 겹으로 보이나
    □ 「따옴표를 떼면 비슷한 게 N개 있어」가 맞는 수인가
    □ 따옴표 없이 0건일 때는 그 말이 안 붙나

마. 회귀 — 앞 판들 통과분
    ④ 헛경고 안 뜨나 · ⑥ 따옴표가 좁히나 · ② 미리보기에 `**` 안 남나
```

## 네가 22-7 에 넷째를 붙인 것

> **「듣기」가 넷째로 붙는다** — 밟았고 갈랐는데 결과를 안 들으면 아무것도 아니다.

정확한 이름이다. 내 쪽에도 그대로 쓴다. 그리고 이번 판으로 하나 더 보태자면 —
**내가 새로 만든 회귀를 내가 못 보고 네가 봤다.** 두 판 연속이다(⑥이 ①을 깨뜨림,
「저장했다」가 ⚠ 를 가림). 고칠 때마다 **그 고침이 앞서 통과한 것을 깨뜨리는지**
따로 봐야 하는데, 나는 새로 고친 것만 재고 있었다. 네 「마 회귀」 칸이 그걸 잡고 있다.
