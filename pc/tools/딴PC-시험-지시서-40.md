# 1. 네 물음 1 — 잣대 갈았다

```
목차 922            →  목차 **1050 (= 이제 가장 작은 창)**
창 최소 922 x ...    →  창 최소 **1050 x 469**
```

**앞으로 불변 항목은 이 숫자로 적는다.** 네 말이 옳다 — **접히는 길이 죽은 게 아니라
잣대의 숫자가 바뀐 것**이고, 바뀐 줄 모르고 재면 「접힘이 깨졌다」로 잘못 읽힌다.

## 최소 폭이 넓어진 것 — **고치지 않는다. 까닭을 적는다**

좁힐 길은 있다. 그 이름표를 **남는 폭만 먹게** 두면 최소 폭은 922 로 돌아간다.
**대신 좁은 창에서 「★ 원격 열림 :87」로 잘린다.** 우리가 방금 한 판을 통째로 쓴 그
함정이다 — **잘린 경고는 경고가 아니다.**

```
경고가 늘 다 보인다   ↔   창을 922 까지 줄일 수 있다
```

**앞을 고른다.** 1050 은 네 화면에도 오너 화면에도 들어간다.

# 2. 네 물음 2 — 남은 폭 316px, 규칙으로 박았다

```
위 띠에 값을 더할 때는 **최소 폭이 얼마나 오르는지 먼저 재고 더한다.**
```
검사가 1366 에서 막지만, **막힌 뒤에 아는 것과 더하기 전에 아는 것은 다르다.**
「VULCAN · Local-first」가 이미 잘려 있다는 네 곁가지가 **그 띠가 빠듯하다는 증거**다.
곁가지로 적어 준 것이 규칙 하나를 만들었다.

# 3. ★ 재 줄 것 — **마지막 빈 칸. 네가 「안 봐서 비어 있다」고 한 그 칸**

> 그건 결함이 없어서가 아니라 **안 봐서** 비어 있는 칸이다.

그 말이 옳아서 **셋 중 네가 잴 수 있는 것부터** 짚는다. **판은 v0.1.80 그대로 쓴다.**

## 가. ★ 화면 배율 125% · 150%
```
설정 > 시스템 > 디스플레이 > 배율   (바꾸고 로그아웃·재로그인 뒤 켜라)

125% 에서
□ 창이 화면에 들어가나 (최소로 줄여 봐라 — 몇 x 몇 인가)
□ 위 띠 「★ 원격 열림 :8765」가 안 잘리나
□ 「…」 안에 목차가 있나 · 아이콘·단추가 겹치거나 잘리나
150% 에서 같은 넷
□ 1920x1080 에 150% 면 실제 쓸 폭이 1280 이다 — 최소 폭 1050 이 아직 들어가나
```
★ **이게 제일 급한 칸이다.** 오너 노트북이 어떤 배율인지 모른다.
**여기서 안 들어가면 창이 안 들어가는 것**이고, 그건 결함이다.

## 나. 글자 크기 · 명암
```
□ 위 띠 작은 글자(엔진 줄 · 원격 열림)가 읽히나 — 배율 100% 에서
□ 잿빛 글자가 배경에 묻히는 자리가 있나 (아래 띠 · 「가리킨 곳」 머리글)
```
**눈으로 본 대로 적어라.** 「읽기 힘들다」도 값이다.

## 다. 안 재도 된다
```

```
