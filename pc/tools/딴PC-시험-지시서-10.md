# VC v0.1.10 — 실사용 4일차

3일차 보고서가 **이 프로젝트에서 제일 값진 한 판**이었다.

「진짜 잡음을 깔았더니 일곱 번 중 둘만 1등」 — 이걸 안 했으면 **1·2일차의 3/3 을
믿고 「뜻 검색은 잘 된다」로 끝냈을 것이다.** 스스로 「내가 깐 잡음은 잡음이
아니었다」고 짚어 준 것이 그 자리를 열었다.

---

## 물어본 것 넷에 답한다

### 1) 3번 결과를 어떻게 볼지 → **네 진단 하나가 틀렸다. 그게 더 중요했다**

같은 묶음을 여기서 그대로 만들어 재현했더니 **2/6 으로 똑같이 나왔다.**
그 다음 낱말 검색과 뜻 검색을 갈라서 재 봤다:

```
'말이 안 통한 것'
  뜻만:  ['말 안 통하는 사람' 0.835, '못 알아들은 말' 0.824, '받침 있는 말' 0.824]
  지금:  ['말 안 통하는 사람',      '못 알아들은 말',      '받침 있는 말']
```

**글자 하나까지 같다.** 낱말 쪽은 **아무것도 안 내놨다** — 물음의 낱말이 어느 글에도
그대로 안 들어 있어서 낱말 검색이 0건이었고, 순위는 처음부터 끝까지 뜻 검색이 매긴 것이다.

그러니 **「낱말이 아직 많이 작용한다」는 틀렸다.** 좋은 추론이었고 증상과도 맞았지만,
갈라 재 보니 아니었다. **원인은 점수가 전부 0.80~0.85 에 뭉쳐 있는 것** —
갈라내는 힘 자체가 약했다.

> 이건 네 잘못이 아니다. 그쪽에서는 두 경로를 갈라 잴 방법이 없었다.
> **틀린 진단이라도 「무엇을 재면 갈리는지」를 알려 줬으면 값을 다 한 것이다.**

### 2) 「조사 어긋나감」이 어떤 말로도 안 나온 것 → **길이 때문이 아니다**

카드 길이를 200 / 400 / 700 / 1200자로 바꿔 가며 재 봤다.
**넷 다 결과가 똑같았다** — 글이 짧아서 길이를 늘려도 담기는 것이 안 늘어난다.

그래서 「짧은 글이 긴 잡음에 밀린다」는 **아니다.** 네가 「추정이다」라고 적어 둔 것이
맞았고, 갈라 보니 길이가 아니었다.

**한 줄짜리 글로 따로 시험할 필요 없다.** 대신 아래 2-나 를 해 달라.

### 3) 잡음을 얼마나 가깝게 까는 것이 적당한지 → **그대로 유지해라**

「말 안 통하는 사람」은 사람이 봐도 그럴듯하다 — **그래서 좋은 잡음이다.**
너무 쉬운 잡음은 아무것도 못 재고, 너무 가까우면 사람도 못 가른다.
지금 정도가 **딱 재기 좋은 자리**다. 3일차와 같은 묶음을 계속 써 달라.

다만 한 가지만 바꿔라 — **물음을 두 갈래로 나눠서** 물어봐라:

| 갈래 | 예 | 무엇을 재나 |
|---|---|---|
| 가) 잡음 쪽 낱말을 쓰는 물음 | 「말이 안 통한 것」 | 어려운 쪽 |
| 나) 표적의 뜻에만 있는 물음 | 「시켜도 안 되던 말들」 | 쉬운 쪽 |

3일차에 이 둘이 갈렸다(가는 틀리고 나는 맞았다). **갈래별로 몇 개씩 맞는지**를 보면
「전체 몇 점」보다 훨씬 쓸모 있다.

### 4) 1-1 을 매번 전부 돌릴지 → **새로 넣은 것만으로 충분하다**

여기 검사가 이미 스물일곱 개를 매 빌드마다 돌린다. 그쪽은 **새로 넣은 것만** 재고,
대신 **네가 새로 지어낸 말**을 더 얹어 달라. 내가 생각 못 한 말이 나오는 쪽이
같은 것을 다시 재는 것보다 값지다.

### 5) `--재보기` 10·30 지점 → **안 해도 된다**

100 과 190 이 똑같이 5ms 였다. 두 배가 돼도 안 느려지는 것이 확인됐으니
10·30 은 더 빠를 것이 뻔하다. **새 자리를 만들면서까지 잴 값은 없다.**
대신 항목을 **500개**까지 늘려 보는 쪽이 낫다(아래 2-가).

## 1) ★★ 뜻 검색 다시 재기 — 이번 판의 본론

**3일차와 똑같은 묶음, 똑같은 물음**으로 다시 재 달라. 그래야 견줄 수 있다.

물음을 갈래로 나눠 표를 채워라:

| 갈래 | 물음 | 1등 | 맞나 | 2등 | 3등 | 정답 등수 |
|---|---|---|---|---|---|---|
| 가 | 말이 안 통한 것 | | | | | |
| 가 | 아래 띠 말이 어색하던 것 | | | | | |
| 가 | 프로그램이 을를 틀리게 붙이던 것 | | | | | |
| 나 | 시켜도 안 되던 말들 | | | | | |
| 나 | 이름 바꿔서 생긴 문제 | | | | | |

**「정답 등수」를 꼭 적어 달라.** 1등이 아니어도 2등인 것과 8등 밖인 것은 하늘과 땅
차이다. 여기서 잰 값은 **7등→2등 · 밖→2등 · 밖→7등** 이었다. 그쪽도 그런지가 질문이다.

「받침 따라 달라지는 말」은 네가 불공정하다고 짚은 그대로라 **뺐다.** 잘 짚었다.

## 한마디

3일차에서 네가 한 것 중 제일 값진 것은 **결과가 아니라 「내가 깐 잡음은 잡음이
아니었다」는 한 줄**이다. 그 말이 없었으면 잘못된 안심으로 끝났다.
그리고 이번에 네 진단 하나가 틀린 것으로 밝혀졌는데, **그것도 값이 있었다** —
틀린 진단이 「무엇을 갈라 재면 되는지」를 알려 줬고, 갈라 재는 순간 원인이 나왔다.

계속 그렇게 적어 달라. 확신하는 것은 확신한다고, 추정은 추정이라고.
