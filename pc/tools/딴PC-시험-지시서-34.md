# VC v0.1.75 — 이행 스크립트(`--판올리기`) · 네 기록이 첫 시험대다

오너가 정했다 — **남은 것을 빠르게 하거나 버려라.** 그래서 둘을 버리고 하나를 만들었다.

```
버린 것  낱말 미끼      740장 실측으로 「고치면 1등 셋을 잃는다」가 나왔다. 한계로 끝.
        충돌본        폰·서버가 붙어야 생기는 문제. 지금은 사이드카 지문 + 지난 판이 잡는다.
만든 것  --판올리기     옛 판 항목을 지금 판으로 올린다. **다시 붓지 않고.**
```

## 무엇을 하나

다시 붓기는 **색인을 새로 만드는 수단이지 노트를 고치는 수단이 아니다**(사람 손질을
지운다). 그래서 노트를 고쳐야 하면 이 길로 온다.

0판 → 1판이 하는 일 셋:

```
스키마 칸이 없다   → `스키마: 1` 을 박는다
앞머리가 두 겹이다  → 본문 맨 앞 `---` 블록을 앞머리로 올린다
제목에 `--` 가 있다 → 꾸밈이 하이픈으로 뭉갠 것. **이름을 바꾼다**(역링크·이력까지)
```

**만든 쪽 실측**(붓기 전 사본 3142장, 전부 0판):

```
올릴 것 3142장 → 3107장 고치고 이름 35개 바꿈 → **아직 옛 판 0장**
다시 돌리면 **0장** (멱등)
```

## ★ 만들다 진짜 버그 둘을 잡았다

### 1. **이름을 바꾸면 출처·지은이가 통째로 사라졌다**

```
전:  --- | id | kind | pinned | created                    ← 출처·지은이·type 없어짐
후:  --- | 출처 | 줄 | 들인이유 | 지은이 | id | … | 스키마: 1  ← 다 살아남는다
```

`rename` 이 제목·본문·갈래·고정·만든날만 옮기고 **`extra` 를 버렸다.**
출처는 **원본 사실이라 되살릴 수가 없다**(어디서 온 글인지는 그때만 안다).
게다가 그 탓에 흡수분 35개가 **「사람이 만든 글」로 보여** 다시 붓기 막이가 막아섰다 —
**안전장치가 제 잘못된 자료에 걸린 것**이다. 별칭도 같이 옮긴다.

### 2. 이름 바꾸기가 **실패하면 그 항목이 두 고리 사이로 빠졌다**

이름도 안 바뀌고 스키마도 안 박혔다(3142장 중 **1장**). **순서를 뒤집어** 이름부터
바꾸고 **남은 것을 모두 줍게** 했다 — 실패해도 두 번째 고리가 반드시 집는다.

### ※ 그리고 내 재는 법이 틀렸다

「앞머리 두 겹 122장」은 **본문의 가로줄(`---`)을 두 겹으로 오해**한 것이었다.
**진짜 두 겹은 0장.** 「앞머리를 뗀 나머지가 또 `열쇠: 값` 꼴로 시작하나」로 고쳤다.

# 재 줄 것

```

## 나. ★ `--판올리기` — **네 기록이 첫 진짜 시험대다**

만든 쪽 기록은 이미 1판 100% 라 **올릴 것이 하나도 없다.** 네 기록은 옛 판 732장이다.

```
VC.exe --판올리기            ← 세어만 본다. 아무것도 안 고친다
```

```
□ 「올릴 것」이 몇 장인가 · 셋(스키마·앞머리·제목)이 각각 몇인가
□ 「이름이 바뀔 것」 미리보기가 그럴듯한가 (`--` 만 빠지고 뜻은 남나)
□ 「사람이 손댄 항목」이 몇 개로 나오나  ← v0.1.74 판정 고침이 먹었나 (전엔 552)
```

★ **여기서 멈춰라.** 숫자를 보고 정하면 된다. **올리면 시험대가 사라진다** —
네 기록은 「옛 판이 섞인 자리」로서 값이 있다. 올릴지 말지는 네가 정한다.

올리기로 하면:
```
□ 올리기 전에 판 적합률·항목 수·그물 맞짝을 적어 둔다
□ VC.exe --판올리기 --쓴다
□ 올린 뒤: 옛 판 0장인가 · 다시 돌리면 0장인가(멱등)
□ ★ 이름 바뀐 것이 **출처·지은이를 지녔나** ← 이번 고침의 핵심
□ 「이건 안 바뀌어야 한다」: 항목 수는 그대로 · 그물 맞짝은 이름 바뀐 만큼만
```

## 다. 사본 치우기 (v0.1.74 · 아직 안 쟀다)

```

□ 숫자가 나오나 · 「사람이 손댄 항목」이 552보다 훨씬 적은가
```

```
