# VC v0.1.8 — 실사용 이어가기 (2일차~)

1일차 보고서가 아주 좋았다. **「안 먹은 말투 다섯」이 이번 판의 재료가 됐다.**

특히 **1-1 을 항목 수로 재 준 것**이 값졌다. 「만들기 어려운 것」·「지우개」가 안 샜다는
말만으로는 못 믿는데, 칠 때마다 항목 수가 05 그대로였다는 것이 **증거**가 된다.
그 방법 계속 써 달라.

---

## 물어본 것 넷에 답한다

### 1) 이름 바꾸기 + 이력을 급한 것으로 볼지 → **급한 것 맞다. 고쳤다**

네 판단이 맞다. **「화면은 있다 하고 지시는 없다 한다」는 어긋남 자체가 문제다.**
어느 쪽이 참인지 사람이 알 길이 없으면 둘 다 안 믿게 된다.

원인도 네가 짚은 그대로였다 — 이력 폴더가 **이름으로** 잡히는데 이름을 바꿀 때
폴더가 안 따라갔다. 이제 같이 옮긴다. 검사도 붙였다.

### 2) 안 먹는 말투를 어디까지 받을지 → **다섯 다 받았다. 선은 검사로 지킨다**

네가 「1-1 과 부딪힌다」고 짚은 것이 정확하다. **말끝을 넓히는 것과 「찾는 말이
지시로 새지 않기」는 서로 밀어낸다.** 그래서 선을 말로 정하지 않고 **검사로** 정했다.

- 넓힌 것: 「좀 …열어봐」 「어제 뭐 썼지」 「할일 태그」(순서 반대) 「추가」 「…적었더라」
- 동시에 **「지시가 아닌 말」 검사를 11개 → 19개로 늘렸다.**
  새로 넣은 것: `추가 요금` `태그 없는 글` `어제 날씨` `일지 쓰는 법`
  `이름표` `지난주 회의` `보여주기식` `열대 과일`

**앞으로 말끝을 넓힐 때마다 이 19개가 안 깨지는지 같이 잰다.** 깨지면 안 넓힌다.
그게 선이다. 네가 「내가 정할 것이 아니다」라고 넘긴 것이 맞았고, 답은 「사람이 정하는
선」이 아니라 「검사가 지키는 선」이다.

### 3) 며칠 이어가는 것이 사람 사용과 닮았는지 → **네 말이 옳다. 오너에게 넘겼다**

> 「나는 지치지도 잊지도 않아서 며칠 전 것을 기억 못 해 못 찾는 상황이 잘 안 생긴다」

이건 **네가 스스로 시험의 한계를 짚은 것**이고, 그 자리를 아는 것이 결과보다 값지다.
오너에게 그대로 전했다. 사람이 직접 쓰는 쪽으로 갈지는 오너가 정한다.

그때까지 **네가 할 수 있는 것만** 해 달라 — 아래 2번이 그것이다.
「기억 못 해 못 찾는」 것은 못 흉내 내도, **오래 켜 두기**와 **항목 늘리기**는
사람보다 네가 훨씬 잘한다.

### 4) 조사를 고칠 값이 있는지 → **고쳤다**

사소하지만 네 말이 맞다 — **아래 띠가 이 프로그램에서 제일 잘 만든 부분이라
거기만 어긋나면 더 눈에 띈다.** 받침을 보고 「을/를」·「으로/로」를 고른다.

### 1-1) ★★ 다시 — 찾는 말이 지시로 새나

**말끝을 넓혔으니 여기가 깨졌을 수 있다.** 1일차와 같은 방법(칠 때마다 항목 수)으로
다시 재 달라. 1일차 여덟 개 + 이번에 넣은 여덟 개:

```
고양이            지우개            열대야           만들기 어려운 것
찾기 힘든 자료    무릎 아플 때      작년에 배포 엎었던 거
추가 요금         태그 없는 글      어제 날씨        일지 쓰는 법
이름표            지난주 회의       보여주기식       열대 과일
```

**하나라도 지시로 새면 그것이 이번 판의 제일 중요한 결과다.**

### 1-2) 또 안 먹는 말

1일차처럼 **네가 자연스럽다고 생각하는 말**로 열 개쯤 더 쳐 봐라.
이번엔 1일차와 **다른 말투**로. 안 먹은 것을 전부 적어 달라.

## 2) ★★ 실사용 — 네가 잘하는 쪽으로

3번 답에 적은 대로, **사람 흉내는 접고 네가 잘하는 것을 해 달라.**

### (가) 오래 켜 두기 (1일차에 못 한 것)

**몇 시간 이상 켜 둔다.** 그동안 이따금 만지기만 하면 된다.

| 잴 것 | 어떻게 |
|---|---|
| 메모리 | 켠 직후 / 1시간 / 3시간 — `Get-Process VC \| Select WorkingSet64` |
| 느려짐 | 검색 한 번, 항목 열기 한 번 — 처음과 나중이 다른가 |
| 그래프 | 어지러워지나 · 항목이 겹쳐 쌓이나 |
| 로그 | `vc-죽음.log` 가 커지나 |

### (나) 항목 30 · 50 · 100개 (1일차에 못 한 것)

한꺼번에 만들어도 된다 — 밖에서 `.md` 를 부어도 되고 지시로 만들어도 된다.
**단계마다** 다음을 본다:

| 항목 수 | 볼 것 |
|---|---|
| 30 | 검색 걸리는 시간 · 그래프가 읽히나 · `[[` 목록이 쓸 만한가 |
| 50 | 같음 + 창 크기 바꿀 때 버벅이나 |
| 100 | 같음 + 켤 때 얼마나 걸리나 |

**「몇 초 걸렸다」를 적어 달라.** 체감도 좋지만 숫자가 있으면 다음 판과 견줄 수 있다.

### (다) 진짜 글 쌓기 (계속)

1일차처럼 **실제로 알게 된 것**을 적으며 써 달라. 하루 3개면 된다.
그리고 **낱말이 안 겹치는 말로 며칠 전 것을 찾아본다.**

1일차 뜻 검색 3/3 은 좋은 결과였다. **항목이 50·100개가 됐을 때도 그런지**가
이번의 질문이다. 후보가 늘면 흐려지는 것이 보통이다.

## 3) 알고 남긴 것 (안 고침)

- **방금 한 지시를 무를 길이 없다** — 네가 짚은 것 맞다. 다음 판에서 손댄다.
  이번엔 안 고쳤다
- **카드 위 줄 정렬** — 「덜 거슬렸다」는 1일차 감각 잘 받았다. 사흘치로 다시 봐 달라
- **별칭 색인 지연** — 드문 자리라 그대로 둔다
