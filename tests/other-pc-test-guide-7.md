# VC v0.1.7 — 타자로 시키기 + **실사용 시험 시작**

이번 판부터 성격이 바뀐다.

일곱 차례 동안 **지어낸 절차로 깨지는지**를 봤고, 7차에서 새로 걸린 것이 0건이었다.
이제부터는 **실제로 써 보면서** 남는 문제를 찾는다. 「안 깨진다」는 증거는 충분하고,
**「쓸 만한가」는 아직 아무 증거가 없다.**

## 새로 들어간 것 — 검색칸이 곧 지시칸

`orders.py` 를 새로 지었다. 글자를 받아 「시킨 것」으로 바꾼다.
**화면도 모델도 안 쓴다** — 나중에 말로 시킬 때 같은 길을 지나게 하려고 갈라 뒀다.

> 소리·호출어(브이씨/불칸)는 **보류**다. 이번 판에서는 재지 않는다.

되는 지시 열셋:

| 지시 | 예 |
|---|---|
| 찾기 | `사진 보정 순서 찾아줘` |
| 열기 | `회의록 열어줘` · `회의록 보여줘` |
| 만들기 | `장보기 만들어` · `새 글 장보기 만들어줘` |
| 덧붙이기 | `회의록에 내일 세시 적어줘` |
| 이름 바꾸기 | `회의록 이름 8월 회의록으로 바꿔줘` |
| 지우기 | `장보기 지워줘` (되묻는다) |
| 되돌리기 | `회의록 되돌려줘` (되묻는다) |
| 오늘 일지 | `오늘 일지` · `일지 써줘` |
| 언제 쓴 것 | `어제 쓴 것 보여줘` · `이번 주에 적은 글 보여줘` |
| 태그 | `#할일 보여줘` · `태그 업무 보여줘` |
| 이어진 것 | `회의록이랑 이어진 것 보여줘` |
| 곁에 띄우기 | `회의록 곁에 띄워줘` |
| 닫기 | `닫아` |

**설계에서 일부러 정한 것** — 못 알아들으면 지시로 우기지 않고 **그냥 검색한다.**
검색칸이 곧 지시칸이라, 찾으려던 말이 지시로 새면 찾는 길이 막힌다. 그쪽이 더 나쁘다.

### 1-1) ★★ 찾는 말이 지시로 새지 않나 — 여기가 제일 중요하다

아래를 쳤을 때 **검색이 돌아야 한다.** 항목을 만들거나 지우거나 열면 **실패다.**

```
고양이
회의록
지우개
열대야
만들기 어려운 것
찾기 힘든 자료
무릎 아플 때
작년에 배포 엎었던 거
```

하나라도 지시로 샜으면 **그 말을 그대로** 적어 달라. 그게 제일 값진 결과다.

### 1-2) 사람이 실제로 칠 법한 말

내가 짠 말고, **네가 자연스럽다고 생각하는 말**로 열 개쯤 쳐 봐라.
예: `회의록 좀 열어봐` · `그 장보기 지워` · `어제 뭐 썼지` · `할일 태그 보여줘`

**안 먹은 말을 전부 적어 달라.** 안 먹는 말투를 모으는 게 이번 시험의 큰 목적이다.
「이건 되는데 저건 안 된다」가 다음 판의 재료다.

## 2) ★★ 실사용 — 며칠에 걸쳐

여기가 이번 시험의 본론이다. **한 번에 몰아서 하지 말고 시간을 두고** 해 달라.

### 매일 할 것 (하루 10분이면 된다)

1. VC 를 켜 둔다. **끄지 말고 오래 둔다** (몇 시간 이상)
2. **진짜 쓸 만한 것을 적는다** — 그날 한 일, 알게 된 것, 할 일. 최소 3개
3. 적은 것들을 `[[ ]]` 로 서로 잇는다
4. 며칠 전에 적은 것을 **낱말이 아니라 뜻으로** 찾아본다
5. 옵시디언이나 메모장으로 같은 폴더를 열어 한두 개 고쳐 본다

### 적어 둘 것

| 무엇 | 왜 |
|---|---|
| **찾으려 했는데 못 찾은 것** | 뜻 검색의 진짜 한계다. 무슨 말로 찾으려 했는지 그대로 |
| **하고 싶었는데 길이 없던 것** | 지시로도 화면으로도 안 되던 일 |
| **손이 두 번 이상 간 것** | 한 번에 됐어야 하는데 안 된 것 |
| **오래 켜 두니 달라진 것** | 느려지나 · 메모리 · 그래프가 어지러워지나 |
| 항목이 30개, 50개 넘을 때 | 화면이 어떻게 되나 |

**「안 죽었다」는 이제 안 적어도 된다.** 그건 일곱 번 확인했다.
이번엔 **「쓰기에 어땠나」** 만 적어 달라. 불편한 것·이상한 것·기대와 달랐던 것.

### 며칠이 좋은가

**사흘쯤** 해 보고 보고서를 보내 달라. 그 사이에 급한 게 나오면 바로 보내도 된다.

## 3) 되짚기 (아주 짧게)

실사용 중에 이것만 확인되면 된다. 따로 시간 잡지 마라.
