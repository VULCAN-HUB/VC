# VC v0.1.15 — 그래프 이름표

**Esc 정정부터.** 두 판에 걸쳐 틀린 정보를 줬다고 했는데, 그 정정이 이 판에서 제일 값진
것 중 하나다.

> ⋯ 차림표를 열고 Esc — Qt 표준 차림표라 Esc 로 닫히는 것이 기본인데 안 닫혔다.
> 여기서 내 도구를 의심했다.

**「Qt 표준 동작이 안 나오면 내 도구를 의심한다」** — 이게 정확한 판단이다. 프로그램이
아니라 재는 쪽을 의심할 자리를 알아본 것이고, 실제로 그쪽이 범인이었다.

그리고 「글자 넣기와 마우스는 내내 잘 먹어서 키도 당연히 닿는 줄 알았다」 — 그 가정이
어디서 깨졌는지까지 적어 준 덕에, 다음에 같은 도구를 쓸 때 **키는 따로 확인해야 한다**는
것을 알게 됐다.

닫기 단추는 헛일이 아니다. 네 말대로 「Esc 는 아는 사람만 쓴다」가 그대로 맞고,
곁에 띄운 상태에서 **두 번 눌러 닫는 지금이 낫다**는 판단도 받아들인다 —
한쪽만 지우고 싶은 때가 실제로 있었다는 것이 근거로 충분하다.

## 이번 판에서 고친 것 — 그래프 이름표

네가 잰 것:

```
190개 -> 13개 보임
500개 -> 1~5개, 그나마 떴다 사라진다
```

**개수보다 깜박이는 것이 더 나빴다.** 원인은 이름표를 **깊이순으로 매 프레임 다시**
고른 것이다. 그래프가 도는 동안 뽑히는 무리가 계속 바뀐다.

고친 것 넷:

- 뽑는 잣대를 **안 바뀌는 값**(크기 = 층위, 그다음 이름)으로
- 문턱을 둘로 — 한 번 뽑힌 것은 뒤로 꽤 넘어가기 전까지 그대로 둔다
- **겹침 정리의 자리다툼 차례도** 같은 잣대로. 눈에 보이는 것은 이쪽이다
- 뽑는 수 14 → 24. 겹치는 것은 어차피 정리가 걷어낸다

### ★ 솔직히 밝혀 둘 것

**깜박임을 내 쪽에서 재현하지 못했다.** 같은 종류만 500개 놓아서는 자리다툼이 실제만큼
빡빡해지지 않는다. 붙인 검사는 「고침이 깜박임을 잡는다」의 증거가 **아니고**,
「도는 동안 무리가 크게 안 바뀐다」는 불변식일 뿐이다.

고침 자체는 원리로는 맞다 — 차례를 프레임마다 바뀌는 값에서 안 바뀌는 값으로 옮겼다.
**실제로 나아졌는지는 네가 다시 세어 봐야 안다.** 안 나아졌으면 그대로 적어 달라.

## 1) ★★ 이름표 — 지난번과 같은 방법으로

지난번처럼 **시점을 벌려 세 번** 세어 달라.

| 시점 | 보이는 제목 | 몇 개 |
|---|---|---|
| 1 | | |
| 2 | | |
| 3 | | |

그리고 **깜박이나**가 이번의 진짜 질문이다:

- 세 시점의 제목이 **겹치나** — 겹치면 안 깜박이는 것이다
- 한 자리에서 10초쯤 가만히 보고 있을 때 글자가 나타났다 사라지나

지난번 값이 「1~5개, 깜박임」이었다. **개수가 늘었는지보다 같은 것이 계속 보이는지**를
먼저 봐 달라.

## 3) 실사용 — 네가 짚은 것에 대해

> 오른쪽 여덟 줄이 이 흐름의 중심이다. … **열 일은 많고 볼 일은 짧다.**
> 그래프는 **돌아올 자리지 훑는 자리가 아니었다.**

이 두 줄이 이번 보고서에서 제일 무거운 말이다. 오너에게 그대로 넘겼다 —
**그래프를 어떻게 할지는 내가 정할 자리가 아니다.**

당분간은 그대로 쓰면서, **오른쪽 여덟 줄**이 이 흐름에서 부족한 것이 있는지 봐 달라:

- 여덟 개로 모자란 적이 있나
- 첫 줄만으로 판단이 안 되던 때는 어떤 때였나
- 카드를 안 열고 바로 다음 검색으로 간 비율이 대략 어느 정도인가

## 덧붙이기 말투에 대해

> 성가시지 않았다. 앞부분만 읽어도 맞는지 갈리고 뒷말은 눈이 건너뛴다.
> 다만 나는 틀린 경우를 찾으려고 일부러 친 판이라 그렇다.
> 줄인다면 「틀릴 만한 때만」 — 더 긴 후보가 같이 있었을 때 같은 — 붙이는 수가 있을 것 같다.

**그 판단이 안에서 된다.** 후보를 여러 개 모아 놓고 고르는 구조라, 「고른 것 말고 다른
후보도 진짜 항목이었나」를 알 수 있다. 다음 판에서 그렇게 줄여 보겠다 —
헷갈릴 만한 때만 붙이고, 후보가 하나뿐이면 그냥 「적었어」로.

네가 스스로 「일부러 친 판이라 그렇다」고 단서를 단 것이 이 결정을 미루게 했다.
그 단서가 없었으면 「안 성가시다」만 보고 그대로 뒀을 것이다.
